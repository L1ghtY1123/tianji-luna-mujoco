## 每次调用的输入与输出

下表是已实现的请求合同，不是本轮真实推理结果。

| 时机 / JEV 选定用途 | 发给 Decisions 的输入 | Decisions 返回及程序处理 |
| --- | --- | --- |
| 初始头部观测 / `initialize_inventory` | 用户指令；头部原始 RGB 和独立标注图；SAM3 临时候选编号、轮廓及局部 RGB；候选实测世界位置；桌面范围；实测目标区域 | 每个候选的同物体分组、类别、桌面范围归属、是否属于搬运任务的概率；RGB 中可见实体总数。程序检查覆盖情况、分配固定全局 ID，生成全部实体清单及引用相同 ID 的搬运子集。桌面和区域使用实测实体加入主清单。 |
| 抓前观测，以及 JEV 选择的原位补图观测 / `associate_inventory` | 三相机原始 RGB 和候选标注图；固定初始参考原图/带全局 ID 的标注/局部图；全部实体清单；当前任务阶段和搬运进度；实测位置、桌面及目标区域/槽位 | 当前候选对应哪个固定全局 ID，是否在任务桌面范围内或为已知搬动实体，是否为背景、错误掩码或无法确认；有目标的搬运成员同时返回当前相对目标的位置判断。程序合并多相机证据，构建一份当前实体集合，不要求每个相机都看见所有物体。 |
| 每次放置并抬升后的观测（包括最后一个） / `verify_transfer` | 三相机当前 RGB/候选标注；初始身份参考；清单和当前阶段；当前物体与目标实体 ID、`region_id`、`slot_id`、实测槽位中心/边界/底面及版本；进度中的释放状态。夹爪释放反馈由程序结合验证 | 各候选的身份关联，以及每个搬运成员的 `at_destination` / `elsewhere` / `unknown` 和置信度。程序要求匹配本阶段分配的区域/槽位，并结合夹爪释放反馈更新搬运清单。仅松爪不算完成，遮挡不算消失，处于别的槽位不算目标已达成。 |

原始深度图不作为图片发送给 Decisions；代码仍用 RGBD 生成实测位置、平面、范围、分割几何和 TSDF/ESDF。Decisions 负责视觉语义与身份判断，不生成运动位姿。当前候选只标临时编号，避免把未经确认的 ID 画到图上误导模型；初始参考标已确认全局 ID。

槽位视觉判断不引入 attachment 全部球体的 XY 投影包含约束。规划仍以固定前端 TCP 世界 XY 为准。目标底面保留完整碰撞间距；本轮没有再次改变规划或 attachment 几何。

正常路径的图片批次为 `1 + 2G`，其中 `G = 冻结搬运物体数 × 搬运阶段数`：初始 1 次、每次抓前 1 次、每次放后 1 次。相同帧分析和已确认释放后的建图重试复用结果，不另发请求。恢复或缺少当前地图时，JEV 可以明确选择额外观测及用途，实际次数以归档为准。

## JEV、SAM3 和失败边界

- JEV 在 `select_arguments` 阶段批量选择技能涉及的有限观测 checkpoint 及用途，`build_scene` 仍然是原子技能。技能内只消费这个选择，不增加 JEV 子决策。
- SAM3 提供掩码，Decisions 判断掩码是否对应固定实体以及当前搬运状态，两者共同作用。覆盖不完整、掩码混合多个物体、身份不确定或 API 失败时明确停止；没有自动补造物体，也没有无限 recover。
- JEV 的 `skip` 或用途不匹配会拒绝依赖该观测的技能，不会偷偷发送图片或切回旧关联。
- 所有实体与搬运子集共享全局 ID 和冻结显示编号；单独抓取后再执行放置，也保留原物体编号和分区容量。
- 三相机联合观测缺少固定碰撞实体时，标为 `mapping_unresolved`。观测本身可保存，建图不能静默删除该障碍并发布不完整地图。
- SAM3 掩码自动修补尚未实现。旧几何关联兼容代码仍保留，但默认 Decisions 路径失败时不会回退；在线视觉方案真正验收后再删除失去用途的旧实现。

## 实际请求如何逐次查看

启用实验保存后，每次真实 HTTP 尝试记录：

- `decisions/calls.jsonl`：观测 ID、JEV 用途、请求哈希、耗时、HTTP 状态和错误索引。
- `decisions/<request_hash>.json`：完整发送问题/输入结构、模型回答和 usage；不写鉴权头或密钥。
- `decisions/<request_hash>-image-NNN.jpg`：该次请求实际发送的 JPEG，JSON 中保留相对路径、媒体类型和 SHA-256，可还原请求内容。

回放的观测图页链接对应请求，审阅 ZIP 和完整 ZIP 都带这些记录。缓存命中不是新请求。失败调用也留记录；Reset/取消时仍在途的响应归档到原实验，不污染新任务状态。关闭实验保存（`save_mode=none`）时不保留图片档案。
