本次修改已部署到 `tianji-luna-web-guangyu`。原观测缺失与回放展示问题已有针对性复测；系统仍存在最终 Decisions 验收不一致，不能宣称所有实验稳定通过。

## 原报错的证据

实验 `4566ae4e95314bcba4a3049b50297488` 已通过产物入盒核验，之后 observe_scene 出现 `visual_identity_unknown`，修订后的观测缺少黑色产物，地图层过期，最终以 `inventory_map_incomplete` 停止。不是本次抓取规划无解。

原头部图中黑色产物仅露出小块。原 `black object` 查询没有候选；这与“返回低分候选”不同。对同一冻结 RGB，`black shape` 返回一个分数 0.75、面积 266 像素的掩码。没有降低 SAM3 或 Decisions 门槛。

普通对象的查询无候选时，技能内部现在有限补充颜色 object/shape 查询。盒子、桌子、标记不走这条补充查询；服务错误不触发替代算法。新候选仍必须通过 Decisions 永久 ID 关联和标定深度处理。该行为不增加任务图节点，也不把颜色直接当成 ID。

分别重放原事件 361 和 378 的 observe 输入，恢复当时已有的 RGBD 桌面拟合缓存，两次均取得原产物 ID，身份来源为 `openai_decisions`，最终可见表面点数分别为 181、180，`missing_geometry_ids=[]`。两只容器使用已验证的实测对应。冻结重放未发布地图、未移动机器人，不等于重新执行了整个旧实验。

原始证据：`data/current-failure-events.json`；重放脚本：`data/current-fix-frozen-perception.py`；结果：`data/current-fix-frozen-perception-361-result.json`、`data/current-fix-frozen-perception-result.json`。

## 高级参数由谁选择

`generate_grasps.arguments.parameters` 允许 Responses 按本次抓取选择以下偏好；非空覆盖必须有 reason：

| 参数 | 合同范围 | 用途 |
|---|---|---|
| grasp_insertion_m | −0.02 至 +0.03 m | IK 和规划前，沿原抓姿局部 Z 施加一次偏移 |
| grasp_maximum_tilt_deg | 0 至 180° | 抓姿相对世界向下的方向筛选 |
| grasp_require_away_from_robot | boolean | 是否启用背离机身的方向偏好 |

未指定的值使用任务开始时的界面默认值。选择在候选生成前冻结，本次规划、执行和运输沿用；下一个物体重新从界面默认值选择。切换目标不会把上一个模型覆盖值变成新默认值。事件 `skill_parameters_selected` 记录来源、理由、覆盖项和实际值，不改写网页持久配置。

此接口目前由 Responses 参数调用使用，未新增 Decisions 通用调参器。硬净距、软代价距离、标定、视觉事实门槛和 VLA 区域不在此覆盖列表中。界面硬净距仍为 5 mm、软激活距离仍为 30 mm。

## 补观测的能力与局限

图支持条件、有限重试和 observe_scene 的 `reuse_current/fresh`。需要移动换视角时，Responses 必须显式选择移动能力，并满足当前地图、空手及碰撞等前提。Decisions 的结果决定执行已有哪条分支；runtime 不暗中插入移动、补拍或固定恢复流程。

必要的数据采集次数不再按目标数设上限；仍记录次数。图循环、重试边界、动作安全和 Responses 修订预算保持。

**能力存在不等于每次初始图都生成了合适恢复。** 原失败实验在执行修订中生成了最多两次 fresh observe 重试；本轮成功图主要包含动作后的常规观测，并未覆盖所有失败分支。初始清单建立和最终验收仍在任务图外，不能宣称它们的所有失败都可走图内恢复。

build_scene 的 contract 已列出 `inventory_map_incomplete`，解释部分观测成功与有效地图完整的区别；结果列出缺失/过期实体 ID 和当前分割查询证据。模型选择恢复方式，代码不强行补步骤。

## 回放图像

用户截图所示的事件 27 本来已经归档了带框 SVG，但前端默认提取其中的原始 RGB 显示，造成“选择身份标注版本却看不到框”。现在缩略图和放大窗口默认显示所选版本的归档标注。

- **识别结果**：归档 RGB 上叠加该时刻的框和永久 ID。框通常来自已关联 SAM3 掩码的外接矩形；身份来源单独列明。这是程序输出展示，不冒充模型输入。
- **原始 RGB**：切换按钮显示同一归档 SVG 内嵌的原始采集图，不重新拍摄。
- **模型输入**：对应调用的归档入口展示实际发送的编码图片、参考图、候选框、问题和回答。

每相机显示实际框数、拍摄时间、标注事件时间及逐框来源。没有身份框的相机明确标为无框，不从其他视角投造框。当前归档不再把未来持物/完成状态画到旧图上。

真实浏览器验证原实验事件 27：头部显示三个框、右腕一个框、左腕无身份框；默认标注、原始 RGB 切换和实际模型输入入口均通过，零 JS 错误、零非 GET API 请求。截图保存在 `data/current-fix-replay-browser/`。

生产代码新增同一请求中的 `completion_condition_N`，逐条保留 Responses 完成条件原文，和总体判断一起记录；任一要求未知/否定仍阻止成功。第三次普通抓放实验的总体与两条完成条件分别为 0.99、0.99、1.0。

第三次实际归档 `skill_parameters_selected` 包含 `source=responses_skill_arguments`、`grasp_insertion_m=0.005`，验证了任务参数从图传入技能并完成物理抓放。它证明一个无需 VLA 的抓放案例可用，不能外推为任意物体、任意场景都能成功。
