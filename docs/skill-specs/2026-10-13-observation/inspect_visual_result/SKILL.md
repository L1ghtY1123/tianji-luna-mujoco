# inspect_visual_result

状态：当前已有，本文补齐目的与接口要求；不表示全部公共字段已实现。遵循 [公共接口](../common.md)。

## 目的和调用条件

从已有抓后/放后图像中提取结果辅助证据。普通验证尚不明确，而相关图像确实有可解释信息时，由 JEV 显式选择；并非 verify unknown 的固定下一步。

夹爪明确持有且没有相反证据时，不因物体被挡住强制调用。缺少动作后帧时先由 JEV 判断是否采集；本技能不能自己拍照。

## 输入和前提

明确 action/phase 的 post_grasp 或 post_place capture、历史绑定的源物体语义、目的地、捕获时反馈、可选参考图和共享视觉预算。当前帧与参考帧分别标注，不能拿参考帧当结果帧。

## 固定流程

校验结果帧和缓存 → 构建有限图像及当前问题 → 一次 OpenAI 图像判断 → 结构/三态校验 → 缓存辅助证据及成本。

最多现有配置允许的四张图，一次 API 请求，与 inspect_scene 共享任务预算（当前默认 8 次）及配置超时。无自动重试；不移动、不采集、不建图、不 attach/detach。

## 输出、状态和错误

输出 confirmed/contradicted/unknown、可见性及图像证据。返回后由 verify_grasp/verify_place 融合实际反馈与几何；本技能不单独提交任务成功。明确视觉反证与夹爪证据冲突时保留冲突，不隐藏任一来源。

同帧缓存不产生第二份独立证据；新辅助结果可以改变相关核验的未消费证据状态。服务异常或图像不可判断时返回 unknown/错误原因，由 JEV 判断下一步。

## 验证场景

已有结果帧不新拍；图像可见但落点关系含糊时可求助；同帧连续请求只复用证据；物体完全遮挡时不能编造已放好；视觉反证不得被明确夹爪位置静默覆盖。
