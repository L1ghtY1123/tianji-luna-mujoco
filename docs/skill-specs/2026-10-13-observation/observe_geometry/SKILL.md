# observe_geometry

状态：拟议技能，尚未注册或实现。遵循 [公共接口](../common.md)。

## 目的和调用条件

回答“指定源物体、目的地或相关区域的实测几何是什么，缺失信息在哪里”。当当前帧还未分析该对象、相关几何已过期或已有具体深度/关联缺口时，由 JEV 考虑调用。

调用者必须明确 `subject` 与 `purpose=source_grasp|destination_place|region_geometry`。三种目的共享固定的测量与关联流程，只改变指定区域及报告字段，不在内部选择任务策略。source 输出不等于抓取可行，destination 输出不等于放置成功。

## 输入和前提

已测得的对象 ID 或区域、所需几何目的、`capture=existing(id)|new`、可选历史关联参考、标定和配置。区域必须来自已观测几何或明确工作区；历史位置不是当前物体位置。

无需执行臂自己的相机可见，也不要求双腕/三相机共同可见。若当前帧无法将历史 ID 关联到实测实例，返回 not_observed 或 association_ambiguous，不制造实例。

## 固定流程

1. 取得指定 capture；查找能复用的同帧分割与几何。
2. 对指定对象/区域执行尚缺的有限分割分析；必要的容器查询仅用于已声明的支撑/目的地几何。
3. 反投影有效深度并按标定合并；保留各相机/像素来源，关联对象。
4. 按目的报告实测表面、支撑/放置参考、质量指标与缺口；未经检查的抓取/路径项为 not_evaluated。

一次最多处理一个对象或一个区域；若必须查询，其对象及支撑/容器最多各一条查询、每相机一次，总计不超过 6 次 SAM3。需要其他对象时由 JEV 选择，而不是内部遍历任务。

## 输出、状态和结束

返回该对象/区域的 geometry evidence，供 generate_grasps、placement 或建图使用。场景观察已提供同样产物时直接复用；不为“精细观察”这个名称重复拍照。

不移动、不建图、不调用 VLM、不在内部试抓或选择恢复。原位重拍没有解除固定遮挡时如实返回缺口/no_new_information；一轮分析结束。几何变化使依赖它的产物失效，历史身份仍保留。

## 验证场景

仅右腕提供绿色点云而左臂执行；三机都有掩码但盒沿遮挡关键区域；目标清晰但 IK 无解不能被本技能伪装成视觉失败；复用已有源/目的地几何；单独 place 时不要求重识别被遮挡的持有物体。
