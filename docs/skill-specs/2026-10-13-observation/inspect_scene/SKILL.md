# inspect_scene

状态：当前已有，本文补齐目的与接口要求；不表示全部公共字段已实现。遵循 [公共接口](../common.md)。

## 目的和调用条件

解释已有 RGB 图中的实例类别、任务成员或空间关系。JEV 看到普通视觉的具体语义歧义，且相关像素可见时才考虑调用。清晰颜色/形状不要求 OpenAI，缺少深度或被遮挡表面也不是让 VLM 生成几何的理由。

## 输入和前提

当前 observation/capture、已测得实例及掩码编号、原始任务与本次语义问题、共享视觉预算。图片与实例映射须同帧；无匹配实例的图像推测不得直接变成目标 ID。已确认 budget 可用，服务按现有配置启用。

## 固定流程

校验及缓存查询 → 对实际图像标注既有实例编号 → 一次有限 OpenAI 图像请求 → 校验结构与实例引用 → 缓存语义证据及用量。

复用已有图片，不拍照、不移动、不建图。最多使用现有配置允许的四张图，一次 API 请求，共享任务视觉预算；当前默认总预算 8 次，沿用配置超时，无自动重试。

## 输出、状态和错误

返回可见性、类别/关系、歧义及证据文字，补充既有实例的语义；不修改实测点云、掩码或 metric pose。不能创建运动指令或恢复路线。服务不可用、超时、身份不匹配和不可见分别返回错误/unknown。

同帧同问题命中缓存，不算新 API 请求或新采集；unknown 保留，是否另取证据交回 JEV。若输入问题改变，只能在预算和当前证据允许时显式请求，不能自动换问法绕过缓存。

## 验证场景

自然语言“红绿物体”普通视觉清楚时跳过；“除工具以外”存在可见语义歧义时可调用；模型返回未登记实例时拒绝；同帧 unknown 不反复请求；隐藏盒底不能被模型补成测量值。
