# Agent 接口与恢复核查

## 本轮边界

沿用当前 Responses 在线编排、Decisions 单题判断、Runtime 图执行和 Robot skills 接口。现有目录及任务外修改保留。实现和验证均在 Luna 应用侧进行。

用户明确删除 OBB 尺寸变化异常判断后，继续授权修复代码和重复实验，要求只依据已有需求和实际错误修改。尺寸判断及其配置、失败码和提示词已从本地与服务端移除。

## 当前接口

| 部分 | 输入与输出 | 执行和失败规则 |
| --- | --- | --- |
| Responses | 自然语言、三相机初始 RGB、技能注册表、CAD 目录、区域和初始状态，生成候选清单及 version=2 graph | 执行前校验类型、引用、参数和前提，校验错误交给模型修订 |
| Decisions | 一个问题及该问题的状态与证据，返回 predicate 或 choice | 每个 HTTP 请求一个 question，yes/no/unknown 与概率分别归档 |
| Skill | 参数 schema、requires、provides、outputs、errors、planning_effects | success 建立声明效果，failure 记录否定或数值失败，unknown 记录缺失或歧义证据 |
| Runtime | 模型生成的 nodes、edges、subgraphs 和绑定 | 跟随声明 edge，保存原始失败主体与回执，边预算耗尽向父 scope 返回 failure |

Registry.describe 同时提供参数与统一 outcome_contract，Responses 与恢复 router 取自同一注册表。

## 恢复与任务清单

恢复以 Responses 生成的 subgraph 表达。其内部调用普通技能，并显式返回失败检查点。Decisions 对异常事实和恢复选择分别提问。每条 edge 的 max_traversals 表示单次 scope 调用中的有限次数，默认 1，模型可按当前任务指定。耗尽时记录 graph_edge_budget_exhausted。父图使用已声明 failure edge，根图返回明确失败。

清单 ID、graph node ID 和 CAD asset ID 分别表示物体实例、控制节点和可共享模型。物体任务通过 input_id、$target 和产物绑定关联清单。恢复必须携带失败主体，已完成动作保留回执。现有清单保留 transfers、processing_history、输入/产物谱系和已验证位置，场景保留局部更新、过期标记及规划前新鲜度检查。

## 数字 ID

新建清单使用从 1 开始的数字 ID，同一清单跨相机和跨观测保持身份。加工产物接续当前清单的最大编号，已消耗输入保留记录，产物创建重试复用既有过程输出的编号。重新初始化仿真生成新清单。

已删除此前自行加入的跨实验 SQLite 分配器、重复 display_id 及其显示映射。现有清单账本继续记录 transfers、processing_history、输入与产物关系，并随实验归档。本轮未增加跨独立任务的持久视觉身份库。

## 放置区域

已删除按物体数量分区、槽位编号、物体独占槽位检查及专属辅助函数。放置请求直接包含实测目标区域。resolve_placement 继续按现有 4→8→16 候选过程寻找 XY，指定坐标使用配置 XY，保留工作空间、IK、碰撞和释放反馈检查。

每个物体的每次转移分别保存目标区域，后续物体的区域更新不会覆盖前一物体的释放证据。图像投影和前端显示使用目标区域或当前候选标签。

## 身份证据与标注清理

删除 demo_completed_tracking 单独识别已交付物体的分支。该分支只提供单相机和文字描述，判断不确定后仍从主身份流程移除对应候选，导致主流程无法使用历史参考图关联该物体。所有有效物体改为经过统一的实例关联入口，交付事实继续使用原核验回执。

修复当前物体图像标签随可见子集重新编号的问题。当前标签直接引用清单永久 ID。历史参考标签也直接使用物体 ID，输入退役后，物体 3 继续显示 R3，物体 6 继续显示 R6。身份输入保留产物参考图的观测编号、历史含义和同帧像素关系说明。

目标区域核验复用现有贴边标签绘制方式。回归检查确认图像维持原尺寸，区域中心保持原始像素。完整实验 cleanup-run6 的目标区域判断为 0.93，原区域显示方式在 cleanup-run5 中为 0.66。两次为独立任务，该结果不构成统计上的单因素效果证明。

## 三相机 OBB

同一次标定 RGBD 采集中的三台相机共同参与分析。对同一永久 ID，融合所有可用相机的世界坐标深度点，按相机记录过滤后贡献点数、缺失视角、采集 ID 和 generation。允许一台或两台看不见。全部缺失时保留清单中的未观测状态，后续目标或地图前提明确拒绝使用缺失几何。

根据用户最新要求，OBB 尺寸变化不再触发异常判断或恢复分支。三相机深度融合和观测来源记录继续用于生成几何。

## CAD 和执行臂

现有 CAD 路径使用 SAM3 掩码、匹配 CAD、标定 RGBD 和 FoundationPose。位姿转换到世界坐标后，离线抓姿使用 T_world_source × T_source_front，并按 A/B 臂筛选。未知物体通过 GraspGen，grasp_targets 对 A 臂作局部 Z 轴半周转换，双臂 Z 相同、X/Y 反向。已有臂绑定候选直接使用 T_world_tcp，避免重复转换。

碰撞校验拒绝旧 voxel 图层。当前接受形态为 OBB、桌面 cuboid 和登记 CAD，其中 OBB 通过规划器 cuboid 表达，CAD 通过 mesh 表达。
