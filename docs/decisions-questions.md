# Decisions 问题与接受规则（2026-11-04）

2026-11-03：加工任务的最终目的地选择明确区分 input selector、来源、中间加工区和产物最终交付。问题内完整保留原指令和当前候选 ID／世界位置；未指定视角时，较大世界 Y 为左、较小 Y 为右，不能被历史参考图的“图像左右”描述覆盖。不判断加工是否已完成、未来是否可达或 CAD 选择；仍需原0.8置信度及与 graph 提案一致。支撑问题独立于是否换视角，unknown 不自行触发运动。详见[本轮审计](batch-and-graph-audit-20261103.md)。

本页只描述当前协议；历史实验以其归档请求为准。一次初始 Responses 编写正常和恢复 graph，运行时 Decisions 返回有类型判断/选项，只选择已有分支，不生成节点、边或自然语言坐标。graph router 的 condition 只问一个明确条件；输入包括当前 RGB、last_result、last_failure、当前事实、绑定 ID 与已验证回执。数值碰撞、IK、工作空间和轨迹由代码与算法检查。

中间目的地的语义许可问题必须同时给出选中区域、放置模式、任务声明工作区及最终目的地的配置/当前测量。仅提供工作区名称，模型无法核对它与选中配置区域的空间关系。此问题只判断本次转移是否符合原要求，不证明落点或运动安全；重新拍照不能补回被状态投影遗漏的配置。

任务技能开始前允许按静态图校验错误最多修订两次 Responses 图。此阶段反馈包含具体校验错误和完整被拒图，Decisions 从最终通过校验的图开始参与运行时判断。

## 输入边界

| 请求 | 模型需要的内容 | 结果范围 |
|---|---|---|
| 身份关联 | C 候选掩码、带日期的永久实例 RGB/掩码参考、三相机视图、历史 RGBD 投影重叠及深度差 | 当前候选与永久 ID 的关联；低历史重叠不直接排除移动后的实例 |
| 当前可见性 | 三相机当前视图、主体描述、已接受的当前身份位置 | 当前是否能看见指定主体 |
| 当前语义判断 | 三相机当前视图、所问条件对应的结构化状态 | 本次语言、关系或完成条件 |
| 视角恢复 | 当前视图、失败所需主体及相关历史参考 | 是否缺少完成该判断所需的视觉证据 |

身份问题分别比较当前候选与一个永久实例。跨相机已确认的同一永久 ID 用于融合测量。

当前 Responses 提议保留采集编号、候选框与拟关联 ID。当前候选与永久实例通过单题 predicate 比较，定位提议用于排列比较次序。跨相机分别确认后按同一永久 ID 融合。候选框重叠仅选择待验证提议。否定保留 proposed_identity_rejected，不确定保留 proposed_identity_unconfirmed，均进入未关联状态。历史位置明确使用过去时，原始 predicate 概率与 choice 置信度分别保存。

身份关联保留 request_hash 与原始回答。已接受身份提供当前定位和可见事实。观测更新清单后，graph 选择当前目标。删除了固定来源清单完整性门槛及整份清单任务语义重确认。新实例登记与恢复视角判断各自独立提问。

TaskSpec 保留已编译的来源和目的地要求。当前物体与对应实体分别完成身份关联后，复用既有语义绑定。current_support 单独选择当前直接支撑或容器。额外放置约束按原指令单独解释，同一任务及目的地复用结果。合并证据保留各题 request_hash，聚合哈希表示该组证据。

图恢复 state 提供技能状态、失败码、参数、执行阶段、数值拒绝原因统计、候选池可重试结果及独立判断答案。完整轨迹和批量规划调试数组保留在实验日志，禁止直接序列化进 last_result 或 last_failure。未知证据仍按未知处理。

原始哈希、掩码数组、标定和完整几何审计保留在程序侧。模型 state 使用明确的图像标签、物体描述及本次所需状态；身份配对收到按该候选和实例裁剪的投影重叠、覆盖与深度差。图片去重仅合并字节完全相同的图像，空候选框列表仍保留该相机视图。数值 XY 提议在已有区域授权后使用结构化候选，不发送图片。

## 问题分工

current_support 核验选中物体当前的直接支撑或容器。结果与 TaskSpec 的来源要求比较，并记录对应采集的来源证据。完成时单独检查来源是否仍有符合要求的输入。

| 问题组 | 只回答什么 | 不要求什么 |
|---|---|---|
| `source_has_remaining_input` | 仅从当前三相机 RGB 判断来源中是否仍有符合原始输入选择条件的物体 | 不判断历史加工或产品交付；完成要求明确的 no，yes/unknown 均不能通过 |
| `identity_N` | 当前 SAM3 主体是否对应一个指定的永久物体 ID | 不判断 CAD 型号、抓姿、任务完成或掩码质量 |
| `visibility_*` | 任一当前相机是否能辨认该物体 | 不要求三个相机都看见，不可见不等于不存在 |
| `cad_model` | 当前已关联主体最适合哪个 CAD 型号参考 | SAM 别名无需等于 CAD 文件名；不估计位姿，不再用事实 confidence 门槛拒绝明确型号提议 |
| `target_*`、`source_identity`、目的地绑定 | 物体/来源/目的地是否符合原始指令 | 不提前要求加工产物存在，不把中间加工区当最终目的地 |
| `current_support` | 核验目标当前的直接支撑或直接容器 | 当前提议或带日期的历史关系作为待验证假设，用一次 predicate 核验。明确 no 后排除该候选，再单独选择其他支撑；unknown 不重问。无假设时从已登记支撑物、none_of_listed 和 unknown 中选择。结合当前图像、测量与历史，保留原始 probability 或 confidence。 |
| `placement_destination_matches` | 本次转移的支撑/容器或配置区域是否符合语言 | 不问是否已经放好，不要求配置区域有可见标记 |
| `placement_additional_spatial_constraint` | 原句是否另有子区域、相对位置或姿态要求 | 只判语言含义；“右侧盒子”的右侧用于选择盒子，不自动成为盒内右侧要求 |
| `placement_xy` | 在已授权整区中选择一个候选 ID | 操作提议；不证明 Z、碰撞、IK，也不要求当前目标仍在原地可见 |
| `placement_candidate_*` | 候选足迹是否满足本次语言位置/姿态要求 | 不夹带 CAD、加工、回观测位姿、最终回位或整体任务完成 |
| `place_result` | 目标是否已在本次指定支撑面/容器内，视觉关系大致正确 | 允许位置误差；不要求释放后 XYZ、SAM3、FoundationPose、OBB、深度或不可见区域标记 |
| `placement_near_target` | 目标底部是否大致在投影标出的指定区域内或附近 | 不要求中心重合或整个物体投影位于框内；标注不是物体检测结果 |
| `unpack_result`、`wrapper_removed` | 当前黑色产物在桌面、粉色输入已被处理 | 不重新判断未来右盒交付，产物几何另由当前 RGBD 建立 |
| `mapping_scope`、`execution_arm` | 选择一个合法操作或参数 | 提议不是事实和安全证明；多个可用选项不要求每个都低概率 |
| `completion_condition_*`、`object_*_condition_*` | 原始任务各项最终要求与各物体完成账本是否满足 | 逐项验收，不重复询问同一组条件的整体合取；历史已确认动作不要求在当前 RGB 重演 |
| 图内 `judgment:` | Responses 明确写出的当前条件 | 技能 success 已含其契约后置条件，重复条件会增加调用，不能替模型隐删 |

## 概率和缓存

事实 predicate：概率 >=0.8 为 yes，<=0.2 为 no，中间为 unknown。事实 choice：合法非 unknown 选项且 confidence >=0.8 才确认。没有把低置信度强改为成功。

操作 proposal（CAD 检索、XY、执行臂、建图范围、声明恢复分支）保留所选值和原始 confidence，不用事实阈值重复否决；明确 unknown 仍返回 unknown。提议之后仍检查真实前提。恢复只选择 Responses 已声明的分支，不提议图外技能或参数。已确认同实例型号和同输入判断可复用，但不得把旧位姿或旧 RGB 标为当前证据。

普通视觉问题使用冻结的当前三相机 RGB。INITIAL/PRODUCT 只是历史外观参考；主图、主体裁剪与 CAD 参考图明确标注。`verify_place` 复用同一冻结采集，通过独立请求分别询问放置关系以及需要时的区域附近关系，保留模型原始回答，不平均/拼接多个概率。全部必要条件满足才确认；明确否定返回 `failure / visual_placement_rejected`，没有确定结论才返回 unknown。

已授权整区的放置核验共享三相机当前视图，每个相机只发送一张图。有目标区域时使用该帧的区域标注图，有历史目标外观裁剪时共享一张参考图。place_result 和 placement_near_target 各自判断支撑和接近目标区域，questions 直接引用共享视图。夹爪反馈保留在执行层，不作为物体清单状态或视觉问题。原始语言子区域和姿态约束由 candidate_selection 路径保留。verify_place 保持独立，完整任务验收由 graph 调用 verify_task_completion。

原位重复相同像素不能提高证据质量。有效 no/unknown 不自动重试；只有没有有效回答的临时网络/429/502/503/504 错误按既有上限重发相同冻结请求。不同视角由 graph 中显式运动取得，且必须已有可用于规划的地图。

放置位置问题优先呈现已投影目的区域的当前视角，保留其余相机；区域轮廓只表示期望位置。视觉核验返回 graph 时保留每题原始概率、判断、observation_id、request_hash 和原释放绑定，不能过滤成空 details。释放后 unknown 的恢复只改善观测并重做核验，不能回到抓取或释放节点重复物理效果。

恢复优先由一次分支选择决定是否回配置观测位姿再观测；配置回位不额外询问是否遮挡。只有额外腕部视角继续使用独立视觉缺失前提题，图中 router 不应先重复同一个问题。保持空手、地图、部分执行与实际运动检查。

夹持问题明确执行臂：A 为左臂／腕部相机 2，B 为右臂／腕部相机 1，头部为相机 3。当前三视角均保留，夹持问题最后给出执行臂腕部图；不能把另一臂空手当成本臂释放的证据。原始反馈只说明夹爪状态，不能替代物体视觉结果。

恢复问题写明原失败 node、skill 和错误，目标是修复该节点的前提，不是提前执行后续任务。是否需要新视角与是否有可用恢复操作是独立问题；没有视觉缺口不意味着地图修复也应停止。`move_to_observe` 可在前提修复后沿 Responses 已声明的恢复分支重新规划，未解决的实际 motor/effect 部分执行仍阻止重试。`build_scene` 的参数效果明确 `observation_map_ready`，selected 与 observation 不混淆。

可见性检查取 graph 的 last_failure，不把中间成功的建图结果当失败。识别失败的实际参数携带永久 ID，问题直接引用该 ID 和已登记的颜色/类别；历史参考只识别主体，当前可见性依赖当前三相机 RGB。缓存绑定原失败、采集和动作 epoch，不能为另一主体沿用旧诊断。

错误报告分别列出具体 question、原回答/概率、门槛、采集和对象 ID。选对 CAD 后的 `observed_support_unknown` 是支撑问题，`visual_identity_unknown` 是实例对应问题，不能统称 CAD confidence 失败。当前差异和真实耗时见 [诊断记录](runtime-diagnosis-20261102.md)。
回位恢复的 `retry_precondition_conflicts` 包含 `observation_motion_scene_ready`：selected 地图没有保留场景授权时不能提供 retry 选项。该事实由已有地图条件计算，不能由视觉概率或模型选择覆盖。修复节点及参数由初始 Responses 声明，Decisions 只选择已有分支。
相同相机图像的身份 predicate 使用一张完整图同时标注 R 参考和 C 候选，直接询问两个标签是否指向同一物体。合并前校验同相机传入的 RGB 字节一致性，分别标明同采集与跨采集情况。跨采集使用当前完整标注图及相关历史参考图。问题直接给出候选主体名称、参考描述和实际图像标签。同一当前主体的多相机分组也使用这些标签，并在对应问题中列出其他可用视角。
`intermediate_destination_allowed` 的明确 no 与不确定 unknown 分开返回。若模型任务字段和完成条件互相冲突，不能通过重问同一张图修复，也不能把否定改为通过。初始 Responses 字段说明明确要求 object subgraph 的最终目的地覆盖加工产物谱系。
## 当前任务验收范围

历史加工/交付里程碑按 selected_input_ids 及其谱系回执判断；all 范围的遗漏输入由独立 source_has_remaining_input 检查。该问题只使用绑定在问题内的当前三相机 RGB，明确 no 才通过，yes 是未完成，unknown 是缺证据。它不重新判断 CAD、加工或最终回位。最终位姿使用实际机器人反馈并独立归档。

Decisions 的有类型 refusal 保留为 unknown / model_refusal，不捏造概率，不当作格式错误或成功，也不因拒答自动重发模型调用。错误名称、错误类型或缺失答案仍按协议错误拒绝。

此规则同样适用于放置核验、拆包结果和身份配对的公共解析器。拒答没有概率，聚合 confidence 保持 null，不能填 0；身份配对遇到拒答保留所有原始答案并返回 visual_identity_unknown:model_refusal，不推导虚构的配对分数。

unknown 原因明确区分 predicate_probability_uncertain（0.2 与 0.8 之间）、choice_confidence_below_threshold（事实选择未达门槛）、model_selected_unknown（模型明确弃选）与 model_refusal。这些是程序可证实的判定来源，不是对模型内部理由的猜测。一次请求的原始答案和实际转换规则一起归档，回放分别显示；操作 proposal 没有事实 confidence 门槛。

router 传递结构化判断，不再转换为 bool/None；后续 router 的 last_result 保留概率、原因、问题和请求证据。明确 yes/no 选择原有边，unknown 选择原有 unknown 边，任何结果都不增加节点。skill 结果已唯一确定恢复动作时直接沿边执行，不再重复询问同一事实。

技能异常的 error_code 统一提供机器错误码。普通 ValueError 使用约定错误文本第一个冒号前的代码，reason 保留含主体 ID 的原始原因。连续恢复问题读取 last_failure.error_code 和 last_failure.arguments，未显式传入 target_id 的技能也记录当前绑定的目标、目的地及执行臂。last_result 表示紧邻前一个节点的结果，router 执行后包含该 router 的回答。router 的不确定回答独立归档，已有技能失败保留供后续诊断使用。

技能直接返回 failure/unknown 时，同样补齐 error_code、调用参数及绑定主体。显式尝试的机械臂记录在该失败结果中，当前已选择臂另存于 selected_arm。选臂失败也更新本次工作空间评估，供后续分支使用。

身份选项的 R 标签同时携带清单中的简短颜色、类别描述，参考图、历史位置与操作记录继续由 state 提供。来源绑定使用简短英文角色问题，当前 RGB、原始指令、统一标签及实测位置共同输入。

恢复所需的当前可见性问题使用永久 ID 与稳定外观，历史描述明确标注时间范围。已接受的当前身份对应复用于同一采集。

抓取相关的补观测判断询问当前视图是否提供估计物体范围和抓取接触面所需的信息。实例识别的可见性问题保持独立。OBB 尺寸改变本身不产生失败，数值规划失败也不直接证明遮挡。

放置核验的必要条件是合取：任何一项明确不满足就返回 failure，即使另一项 unknown；同时保留 failed_criteria 与 missing_evidence。只有尚无明确反例、仍缺必要证据时才是 unknown。两种状态都不自动触发观测或移动。

placement_near_target 明确引用参考图中目标的颜色、类别及当前支撑物，判断其落在表面的位置是否大致位于投影区域内，并允许视差和小幅放置误差。支撑关系和区域位置各用独立问题，不询问夹持/未夹持。

当前逐项审计、unknown 生产方与碰撞回放说明见 [2026-11-03 审计](replay-question-audit-20261103.md)。同帧身份提议明确被否定时，其余身份仍未确定，派生 unknown 必须保留 proposal_rejected_identity_unresolved 与原始低概率；不能误称为模型中间概率。

补充视角直接询问 `recovery_view_limited`：当前任务所需视觉证据是否因画外、裁切或遮挡而不可得。原有 0.8 门槛不变；具体原因的独立概率只作诊断，不要求某一种原因也越过门槛，不相加概率。明确 no 或 unknown 仍禁止该恢复移动。问题绑定原失败和永久主体 ID，图仍需显式声明补观测节点。

## 独立请求与身份时间范围

每个 Decisions HTTP 请求只有一个 question。技能可复用同一冻结采集发起多次请求，再按契约汇总各自结论。每个结论保留自己的请求哈希、原始答案和转换原因。缓存保存原始回答，调用方解析相互独立。

同一时刻先用标定 RGBD 建立跨相机对应候选，再逐对判断是否为同一物理主体。通过的对应才能共享后续永久身份结果。跨时刻身份关联独立选择一个 R 标签，对应永久 ID，输入包含当前 RGB、测量位置以及清单已记录的转移、释放和加工历史。已接受的身份对应直接提供当前可见事实，恢复视角判断按需单独请求。C 标签在图像、state 和 question 中一致，内部 candidate ID 留在程序证据中。每个身份请求只突出该主体的 C 标注及相关 R 参考。参考与当前 RGB 像素相同时，明确标注相同图像，并提供同图框 IoU 作为几何输入。该特征不直接分配永久 ID。

默认 selection_order=explicit，Responses 通过 graph 调用路径决定物体顺序。inventory 与 nearest 仅用于自然语言明确要求相应顺序的任务。清单编号本身不规定操作次序。

初始顺序优先满足任务依赖，再优先抓取可见抓取面暴露、遮挡少、周围间隙充足的输入。具体顺序由本次 Responses graph 表达，技能验证实际可行性。

来源与观测实体目的地的角色选择使用 task_role_selection 范围。只发送原始指令、确认后的候选属性和当前标注 RGB。候选说明显式表达实测世界 Y 对应的机器人左侧、右侧或中线，保留三维位置以支持其他相对关系。图提出的角色 ID 留在程序比较步骤，身份和当前位置已经确认，角色选择专门判断指令指定哪一个实体。配置区域授权、输入成员和实际容纳关系继续独立判断。

已验证释放的实体使用原有执行链和当前深度范围提出关联，再逐候选核对当前外观。请求携带该永久实体的颜色、类别、外观关键词和已验证释放采集，使用候选所在相机的一张完整标注图。C 标签在请求和图片中逐项对应。问题判断候选是否符合已释放目标，避免要求从静态 RGB 证明物体可移动。明确 yes 且 confidence 达到原门槛后才合并身份，拒答和不确定保留原始证据。

已授权整区的放置核验按问题裁剪 state。支撑与区域问题只接收目标外观及目的地描述，只有夹持问题接收实际夹爪反馈。绑定 ID、执行哈希和审计来源留在程序证据中。各请求复用同一冻结图片，阈值与判定规则保持独立记录。

视觉缺证据的有限恢复覆盖目标、目的地绑定及释放后核验。Responses 显式编排建图、移动、分析和重试检查点。配置回位无需额外视觉缺失谓词；额外腕部视角才独立核验当前视觉缺失。中间建图成功保留原失败，原检查点重试成功后解除活动失败，历史事件保留。

身份请求传递带原始观测编号的历史实测位置，与当前候选的世界坐标共同提供身份关联证据。未见、提议更新和新任务保留原测量时刻，接受新的 RGBD 测量后才更新该记录。

身份题在 `correspondence_subjects` 中直接列出本题的当前标签、相机、SAM 外观提议及参考实例的类别、颜色、历史描述。已有同次接受对应时，明确列出对应标签／相机和同一世界坐标下的两组表面测量及距离；否则列出带日期的历史位置比较。距离只帮助 Decisions 读取现有深度证据，不设身份距离阈值，不将共址当作同一实例，不删除其它实例与操作历史。容器和内容物仍是不同身份。每次 HTTP 只问这一对主体的对应关系。

如果该实例的释放已在当前采集核验，而历史位置来自更早观测，则明确标注「历史位置早于本次释放」，保留历史位置和操作记录，但不再生成当前点与搬运前点的位移摘要。该释放回执只帮助解释时间变化，不自动确认 SAM 候选的身份；仍由单题 Decisions 根据当前图像关联。当前同帧的已接受视角之间仍可比较表面测量。

verify_unpack 的产物出现与包装消失分别使用一次 Decisions 请求，每次共享拆包前与当前三相机图像。两项事实可以由不同相机提供证据，明确否定返回 rejected 并沿 failure 边，缺证据返回 unknown。程序继续校验动作回执、采集时序、目标绑定与测量来源。

verify_unpack 内部采集当前三相机 RGBD，并建立加工结果与产物 ID。后续 observe_scene 使用已登记的产物身份获取掩码与几何。

身份细节图使用保留周围区域的原始 RGB，不将轮廓叠加到紧裁剪里；当前全景继续提供 SAM3 掩码、候选标签及三相机视图，深度与历史状态不变。避免小目标的外观和接触/分离关系被裁剪、描边遮蔽。

身份问题明确写出当前 mask、待比较永久实例和该实例的日期参考描述。已确认同采集位置与历史位置分开措辞；容器与内容物即使框重叠也不是同一实例。RGB、掩码、深度和状态不变，只修改问题表述；保持原概率阈值，正例与反例共同验证。

## 初始登记的原子判断

初始提议在指定相机的当前 RGB 上标为 P，已有实例参考标为 R加永久 ID。每次 predicate 只判断一个身份对应；已有实例均被排除后，单独判断 P 是否为真实外部实体。桌面支撑和容器也是可登记实体。父容器关系属于后续支撑核验，身份题仅接收主体外观与定位。unknown 保留为未确认提议，只有确认后分配新永久 ID。每批后续提议会比较本批已经登记的实例。

初始登记与场景感知共用身份命题构造函数。登记命题直接列出当前主体的提议描述和参考主体的带日期描述，区分矩形中的容器、内容物和支撑面。RGB 和 P/R 标注共同提供对应依据，原始概率按配置门槛解释。

初始登记前复用感知层 SAM3 缓存定位提议主体，并使用注册深度和标定计算当前可见表面。候选框与 SAM 框重叠用于选择待核验主体。Decisions 接收 P 的掩码轮廓、实测质心/包络/点数，以及参考实测表面投影到 P 所在相机的 IoU、覆盖率和深度残差。已确认的同批主体可作为带掩码参考，随登记结果交给后续 observe_scene。缺少掩码的提议继续如实提供 RGB/框，缺失几何单独标记。SAM3 结果和投影统计提供判断依据，永久 ID 继续在 Decisions 确认后分配。

## 动态批处理与 Decisions 边界（2026-11-08）

all/count 任务采用共享处理子图。每件交付后显式回配置观测位姿，再调用 fresh observe_scene 和 select_target。初始 target_refs 保存初始候选，新观测登记的匹配实例可以进入同一循环。all 以当前来源盒确认清空结束本批，count 按请求数量验收。循环预算独立于初始数量，预算耗尽返回失败。

Decisions 负责实例身份、CAD 选择、任务成员关系、语义位置、来源为空的视觉判断，以及多种合法恢复方案之间的选择。单个候选、已绑定参数、数值规划结果、反馈和版本检查、唯一恢复出口直接由程序处理。普通盒上释放按用户指定规则登记入盒，无需再询问落地关系。工作区轻放和额外落地要求继续视觉核验。

时间记忆记录 container_entry、永久 ID、加工谱系和历史测量。回执来源为 operator_container_release_rule。空间记忆发布对应已测容器的整体包围范围，geometry_source 为 container_occupancy，object_pose_measured 为 false。新单件测量替换该范围。容器几何失效会使依赖它的占据失效。所有后续轨迹仍检查当前碰撞世界。

每轮实例关联使用执行层投影的 association_scope。当前输入及其产物优先，已交付实例保留物理历史并按需比较。单个身份谓词的历史证据限定到被比较实例，当前已接受主体继续保留标注与几何，帮助区分相似物体。新实例登记前仍检查全部可用历史身份。已交付内容物只有在入盒回执、有效空间占据和当前容器 RGBD 对应一致，且通过已有容器位置稳定性检查，且候选完整有效表面位于占据范围内时，才记录为 deferred_candidates。记录包含采集、场景版本、容器、回执、测量范围和占据范围，identity_assigned=false。来源盒、工作区及未完成物体的已知支撑容器继续完整关联。占据失效、容器对应缺失、候选伸出范围或后续任务重新操作该容器时，恢复通常关联。空间记忆继续保留交付实例的占据；单件位姿保持未测量。association_scope 参与观测复用键。

当前支撑判断同样按单题投影。关系谓词仅提供当前物体和被询问支撑的标签、身份参考及几何；支撑选择题保留全部候选支撑。三相机当前 RGB 和原始概率阈值继续参与判断。

新实例谓词在全部历史身份比较明确否定后提出，图像只携带当前候选及已接受当前主体，供重复片段判断。图像数量限制作用于最终单题请求。140 个历史实例的构造检查得到单题 2 张图像。

关联范围同时覆盖当前运动所需的目的地几何。当前存在未完成输入或产物时，目标盒内容物恢复逐件关联，优先在加工准备和携物遮挡前取得当前 CAD/OBB；直接搬运任务持续保留这项目的地几何需求。逐件交付后尚未选定下一输入的观测可使用有效容器占据。空间占据保持参与全部数值碰撞检查。

支撑谓词使用单题 A/B 标签，并在结构化输入中保留永久 ID 映射。支撑判断在当前 RGB 上标出被询问物体，并将已测桌面边界按当前相机标定投影为带永久 ID 的多边形。标注保留原桌面测量日期，当前可见关系继续由 Decisions 判断。优先展示同时定位物体与支撑参考的视图，保留全部三相机画面。

支撑题保留当前其他已关联主体的 C 标签，历史参考仍限定到本题主体与支撑。三相机全图之外，提供一张由最清楚当前主体视图裁出的原始细节图，来源相机及裁切坐标明确归档。
