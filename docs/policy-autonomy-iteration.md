# 2026-10-26：编排自主性与实测迭代

本次修正依据用户明确要求：Responses 决定任务图；Decisions 判断视觉、语义及可行候选选择；skill 求解其所选能力。不能把拆包演示的动作顺序、回位、执行臂或落点写成通用任务要求。

## 查明的问题

1. 旧 `verify_unpack` 即便获得动作后视觉与深度，只要不在配置观测姿态仍返回 unknown。观测、建图和抓取又要求指定姿态。这是人为合同限制，不是 Responses 自主推导的必要路线。图校验器虽没有插入节点，但这种合同仍会迫使模型输出固定步骤。
2. 旧配置默认附带任务末尾回位要求；目的地白名单只允许最终目标或拆包处理区，阻止模型选择其他中转支撑。
3. 源盒关系检查曾误用露出的盒底放置区域。真实记录中物体中心 Y=0.48083380m，露出盒底边界 Y=0.48332313m，相差2.49mm；物体位于发布盒子整体边界内。可见盒底空闲区域不是容器完整范围。盒子占用外边界只能帮助推导抬升高度，不能证明未知容器内部自由空间。
4. 对盒子目的地增加盒底采样检查后，真实实验106e74在选臂时被误拒绝。来源仅 A 可达；可见盒底121点 A 为0、B 为26。但后续反证查询显示：Run3 当前注册完整腔体235点，在盒沿上方 z=0.7535/0.8035/0.9035m，A 分别有1/5/13个位置候选。这不证明完整搬运可行，却推翻了“盒底不可达即运输不可达”。容器选臂阶段应将目的地标记为待检查，由当前完整容器几何和真实抓姿检查上方目标；不能据此强制中转。
5. 另一处坐标混用是将 TCP_Link 法兰位置送入夹爪前端工作空间 atlas。atlas 的查询点在法兰局部 Z+0.185m；应只转换 atlas 查询点，实际 cuRobo 目标仍保持 TCP_Link 矩阵。
6. 通用放置仍按物体清单分格，并以整格互斥核验释放。这会把共享桌面当作一个独占槽位。现在未要求精确落点的转移共享所选支持区域，实际候选经过持物投影、规划和碰撞检查。

## 当前边界

- 初始 Responses 输入：自然语言、初始 RGB、场景配置知识、实际初始事实、技能合同与说明、图 schema。输出不可变 TaskSpec、实体清单提议和带条件、循环、结果绑定、失败分支的策略图。正常一次，修复与修订最多再两次；执行器不自动补动作。
- 当前位置证据充分即可确认拆包产物，产生独立 ID 及输入输出关联。不自动回位、不伪造“已观测姿态”。当前 `observe_scene` 可以复用核验采集完成身份与测量关联；后续消费者仍要求真实 ID、测量与版本绑定。是否换视角、移动或再观测由模型图决定。
- 用户明确要求回位时，Responses 设置 `completion_pose=observation`，完成时按真实关节反馈验收；遗漏回位节点不能由 Decisions 的 yes 掩盖。未要求时字段默认 null，默认场景不再添加这个完成条件。
- 模型可绑定其他已识别实测支持区域作为中转。存在用户语义约束时由 Decisions 检查中转是否允许；中间放置不会篡改最终目标或冒充任务完成。
- `choose_arm(auto)` 检查双臂来源及相应能力所需的候选证据。桌面位置采样是初筛；容器上方目标在当前完整几何与实际抓姿可用前保持待检查，不拿盒底否决。任何位置采样都不代表完整 TCP 姿态、路径或覆盖已通过。当前转移选臂不绑定后续转移；重绑目的地使旧选臂与计划失效，图合同同步声明失效事实。
- 用户不要求精确点时，桌面或盒子内部按真实边界生成有限候选。实际放置与运输最多12次纯规划尝试，记录具体落点、每次失败、耗时及尝试数。覆盖不足、过期证据、服务错误和协议错误立即停止，不能伪装为换点重试。
- 图校验只检验技能真实前提、结果来源、对象绑定与预算，不插入“回位—观测—抓取”等模板。新增技能仍通过独立合同、schema 和 handler 注册。

## 覆盖缺口仍须保留

三相机只建立已观测清单实体；未观测空间不视为空闲，原始深度可独立用于运动可见性。已有真实实验在肩部 Link1 的轨迹覆盖检查停止，不能把这说成 SAM3 分割失败。

对相同记录的533个碰撞球进行独立采样：初始帧相对初始球集合的最大数值伸出约66.6nm；后续帧128/256的球面最大伸出约0.148/0.324mm，添加保守包络后约0.276/0.435mm。这说明后续确有碰撞模型体积进入初始已知体积外，不能仅靠调整纳米级比较容差解决。它不证明物理机器人发生碰撞，也不证明未观测区域存在障碍；只说明当前覆盖证据不能批准该路径。

历史七次真实实验及其版本见 [逐步核查实验](step-audit-experiments.md)。替身回归测试只证明逻辑行为；完整搬运、VLA 和最终放置必须另用真实仿真验证。
