# 抓取接触范围与模型输入核对

## 第二段的碰撞球

原配置按执行臂排除两侧 Link3 链接，每个链接三个球，每臂六个球。球编号使用 YAML 中各链接列表的 0、1、2，GPU 后端的全局索引随配置变化。

本轮按用户允许扩大夹爪接触范围的要求，加入两侧 Link4 连杆，每侧十四个球。当前每臂四个链接、三十四个球。

|执行臂|Link3 夹指|Link4 连杆|合计|
|---|---|---|---|
|A|gripL_Link3_L、gripL_Link3_R，共 6 球|gripL_Link4_L、gripL_Link4_R，共 28 球|34 球|
|B|gripR_Link3_L、gripR_Link3_R，共 6 球|gripR_Link4_L、gripR_Link4_R，共 28 球|34 球|

“接触垫”是此前对 Link3 内侧夹持面的软件称呼，硬件模型使用原有 URDF 的 Link3。原先只允许 Link3 的范围属于项目实现选择。本轮把 Link4 纳入，允许这些部件与选中目标接触，以适应较深抓取。

官方 plan_grasp 在 goalset、grasp、lift 求解时临时关闭传入链接，在 approach 求解时恢复。应用的第二段和闭合命令校验按链接与目标的配对处理，继续检查这些链接对盒子、桌面和其他障碍的碰撞，另一臂、其余部件和机器人自碰撞也参与校验。第三段完成并通过机械反馈后建立 attachment。

## Responses 为什么被拒

修改前八次在线任务共十五次 Responses 请求，HTTP 状态均为 200。八份输出被本地图校验拒绝，七次任务最终获得通过校验的图。第一稿直接通过的是两次。一次任务在三稿均被拒后停止。

|拒绝原因|实际含义|
|---|---|
|graph_edge_unknown_node、unknown_subgraph|边或调用引用了未声明的节点/子图|
|graph_unreachable_nodes|声明节点没有可达入口|
|unbound_policy_reference|某条路径使用了尚未产生的实例绑定，例如产品产生前使用 $product|
|planning_precondition_not_satisfied|某条路径缺少技能前提，例如重观测后建图前缺少 observed|
|graph_observation_recovery_missing|项目额外要求的观测恢复覆盖未满足|

观测恢复覆盖检查属于编排完整性要求。它要求相应正常失败出口能够到达 Decisions 选择的移动并重观测路径，因此有明确停止出口的图也可能被此项拒绝。拓扑、状态前提、恢复覆盖使用同一个 responses_invalid_plan 错误归档，需查看具体 validation_errors。

run-08 首稿输入文本 99,928 字符、28,737 输入 token，输出包含 109 个节点、285 条边。简短模式此前仍发送了 35,272 字符的完整技能描述。本轮改为简短 capability 描述，保留所有参数、前提、效果、结果和状态失效规则。

run-09 首稿输入文本 67,568 字符、23,250 输入 token，输出 62 个节点、161 条边。该首稿仍因观测恢复覆盖被拒，第二稿通过。这是一次输入缩减后的样本记录。

## 粉色物体与蓝盒的误关联

run-07 的错误发生在 bind_proposals，早于 graph 中的 observe_scene。请求使用同一次采集的相机 2 粉色主体 P 和相机 3 蓝盒参考 R389。蓝盒的矩形包含其内部粉色物体。

实际请求包含三相机 RGB、P/R 框和描述，参考标记为 mask_contours_supplied=false。初始登记通过通用 DecisionsJudgments 接口，subject_geometry 与 reference_projection 当时没有接入。程序保存的深度、标定和后续感知路径的掩码，尚未进入这次判断。原请求约 2,077 输入 token，模型返回同一实体概率 0.86，随后重复 ID 检查停止运行。

上轮新增初始确认时遗漏了这条输入链路。现有证据支持主体包含关系歧义和初始输入缺项，冗余是否直接造成该误判需要独立消融证据。

## HoloAgent 方法接在哪里

HoloAgent-0 §4.2 将已有三维实例投影到当前相机，与当前二维掩码计算 IoU，用于持续身份关联，同时以全图、掩码区域和局部框的 SigLIP 描述支持语义检索。项目借鉴的是三维表面投影、掩码重叠和深度残差，使用 SAM3 与 Decisions 完成当前判断。此前该证据进入 DemoVisualInventory.resolve 的 observe_scene 路径。[论文 §4.2](https://arxiv.org/html/2606.23565v1#S4.SS2)

本轮初始登记复用感知层 SAM3 缓存、已有外观回退词和机器人自身点过滤。当前 P 带分割轮廓、实测质心、包络及点数。已有参考表面投影到 P 的相机，提供 IoU、覆盖率、深度残差和日期。同批已确认主体的掩码参考传给后续 observe_scene，完整观测仍由原有记忆事务持久化。每次 Decisions 请求一个问题，比较中的实例决定输入范围。

原错误采集的新版本冻结验证中，蓝盒表面投影与粉色掩码 IoU 为 0.01248，覆盖率 4.08%，重叠像素深度残差中位数 0.12624 m。同一粉色主体的重识别 IoU 为 1，残差接近 0。四个实体正确区分，正例正确重识别，十四次单题判断通过。粉色/蓝盒同一实体概率为 0.00，粉色正例为 0.99。
