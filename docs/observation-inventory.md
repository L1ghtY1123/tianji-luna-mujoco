# 观测、物体清单与碰撞场景

2026-10-14 三路线实现说明。旧版验收见 `data/observation-inventory-20261013/`，本版验证见 `data/transfer-routes-20261014/`。通过单元测试不等于实际抓放验证。

## ID 的唯一规则

2026-10-15 来源约束修正：首次检测范围不等于任务成员范围。盒源路线只允许有唯一实测盒底关系的候选成为 required，按最新要求使用 50% 可见点 XY 重叠门槛（不是完整物体可见率）；缺证据保持 unknown，由外层 JEV 判断是否排除或补充观察。JEV 同时得到可见中心与实测盒底范围的分离距离，避免把明显在桌面的其他物体纳入盒内搬运任务。清单写入和目标绑定各检查一次；历史 initial_source 保留跨桌面中转身份。这个限制不是固定颜色或抓取顺序，也不删除场景障碍。

技能调用记录现在遵循“选择 skill → JEV 确定参数 → skill_start → 固定算法 → skill_complete”。此前 runner 在参数选择前记录 skill_start，导致建图界面显示中途出现 JEV，且算法耗时包含参数决策；已统一修正。最新 assess_task 输出与当前清单完全相同时，JEV 输入只保留一份清单，历史不同版本仍保留。

内部 ID 是一次观测关联得到的物体身份，不是某一张 SAM3 掩码。显示编号从 1 开始，首次按头部相机到可见点云中心的距离从近到远分配；后续不重排、不复用已完成编号。三条搬运路线在首次有效初始观测后固定清单成员；后续新检测继续参与碰撞场景，但不自动新增搬运目标。只有 JEV 明确选择重枚举时，才登记指定歧义集合中的替代 ID。未指定具体目标或顺序时，默认按显示编号递增；明确指定对象或顺序时由 JEV 按原文选择，等价目标才参考 TCP 距离。

两类关联分开进行：

SAM3 的 cube 查询为空或没有颜色限定时，仅增加一次保持颜色条件的 block 查询，结果按帧缓存。跨相机关联之前，同相机多个查询产生的掩码只有双向覆盖均达到 95% 才合并，避免同义词重复计数；单向包含不合并。

1. **同一时刻、跨相机**：SAM3 给出各相机掩码；用各自实际深度反投影，在世界坐标中检查可见表面与掩码重投影。优先以头部掩码为共同参照；没有头部掩码也允许腕部提供几何。同一相机的两个检测不能随意合成一体。一个补充检测同时符合两个组时，将该检测记为歧义，不纳入目标表面；已明确的组仍可使用，原始深度保留在观测记录；语义过滤图若仍有该歧义则拒绝发布，不能删除后当空位。深度冲突按投影位置附近四个像素检查，避免斜表面最近像素取整造成假冲突；不按相机数投票。
2. **前后时刻、清单 ID**：只比较同类别、同颜色候选，并读取该 ID 的 `unmoved`（未搬动）、`held`（持有）、`released`（刚释放）、`placed`（已放置）状态。先匹配未搬动物体、持物和目的地，再在目的地区域匹配已放物体，最后处理刚释放的唯一剩余候选。未搬动物体的具体类别与颜色在前后均唯一时，先按该明确外观延续 ID；多个同类同色对象不能走此规则。头部标定和位姿相同时比较掩码 IoU，至少 0.50，且存在合格竞争项时最优项比第二项至少高 0.15。没有可比较头部掩码时，比较实测表面，5 mm 范围内双向重叠至少 20%。未知/泛称类别不使用唯一外观关联。每轮匹配都要求新旧双方唯一接受对应；冲突保持 unknown。

不同 SAM3 查询也可能把同一盒壁分别报成容器和方块。进入清单前先去除这种类别别名：将双方点云分别投影到对方实际掩码与深度，在 5 mm 表面容差内，双向可比点至少 95% 一致、各自全部点至少 50% 有匹配且至少 30 点支持，才接受单一对应，保留明确容器/具体类别。相同类别不走这条去重规则；盒内物体只被盒子掩码包含时，反向支持不足，不会被删除。保留 `semantic_duplicate_evidence` 供追溯，几何以去重后的 SAM3 实例进入语义图；初始背景图仍保留有效原始深度。该补充规则在后续全部抓放验收发现盒壁重复后加入，不把此前关联数据集的评分扩称为它的独立验证。

这些数字是匹配门槛，**不是正确概率**。5 mm 是点云表面一致性容差，不是两个物体的间距；没有“相隔 12 cm 才能分开”的规则。能否将相隔 5 cm 的物体分开，还取决于实际掩码和深度。跨相机几何检查沿用现有深度/FOV/前景遮挡检查。

释放和已放置 ID 只在已关联目的地的当前实测区域内找候选：必须有 `above_observed_bin_floor` 或 `above_observed_marker` 关系，实测点 XY 落入比例至少 50%，与既有来源区域使用同一关系门槛。该门槛只说明候选受到目的地区域测量支持，不是关联准确率或完整物体包含率；不再叠加 90% 辅助门槛。只有 `placed` 对象的历史实测关系已经支持同一目的地时，才可在该区域用上述头部 IoU/表面规则对应旧位置，区分先前已放入的相同物体。刚释放对象不比较释放前掩码；尚无目的地测量历史的已放对象也不使用原始来源位置。

在上述匹配后，其他同类别同颜色的历史 ID 全部已匹配、目的地已匹配，且目的地区域只剩一个未关联同类检测时，才用 `released_target_unique_destination` 延续当前搬运 ID。候选为零、多个或同类历史仍未知时拒绝指定身份，保留候选和测量关系证据。后续观测持续传入该 ID 的放置目的地，不会因为清除 holding 而重新回到原始位置匹配。2026-10-14 最新简化验收采用放置动作完成及开爪反馈，计为释放成功，不核验最终落点；身份更新仍使用后续实际观测。清单外的新检测保留为障碍物，不进入历史任务身份竞争。

夹住及释放中的身份由已选择 ID、已执行动作和夹爪反馈绑定。夹爪反馈说明持有状态，不能独自证明夹对了哪个对象。`held` 关联只使用当前 TCP 下持物参考的世界点云预测，仍要求 5 mm/20% 表面支持和一对一唯一对应；旧来源点云、旧头部掩码和唯一颜色都不能替代持物位置证据。没有持物预测则报告 `held_prediction_missing`。预测位姿不会伪装成当前相机观测。

内部 `associate_inventory(..., identity_states=...)` 接收 ID 到状态记录的映射；`released/placed` 记录携带历史 `destination_id`，`held` 通过 `point_predictions_world` 接收当前世界坐标点云列表。兼容已标为 `action_prediction` 的持物参考及旧 `released_target` 输入。不修改显示编号、不自动重枚举、不触发任何恢复；返回实际 IoU、表面重叠、目的地测量关系、已对应同类 ID 和 unresolved 候选，明确 `score_is_probability=false`。

对相同工件大幅移动后出现的多对多歧义，程序保留原 ID 并给 JEV 候选与证据。JEV 可选择重新观测、有限图像辅助或重枚举明确指定的歧义未完成集合。重枚举将原记录标为 superseded，新增编号，不重置完成记录；用户明确要求的历史 ID 不能被静默替换。完全相同的物体在不可见期间交换位置，仅凭前后 RGBD 无法保证恢复其物理身份；本清单不提供物理序列号级追踪。

## 清单和场景分别更新

- 清单记录编号、初始语义、状态、阶段及历史目的地、当前可见性、最近实测位置和关联证据；保留最近观测属性（类别/颜色/来源相机/测量关系/视觉语义）及 observation_id、instance_id 引用。原始掩码、点云和轨迹留在观测/实验记录，通过引用追溯，不复制到 JEV 的精简清单。未知不补猜测。不可见与未完成/已完成独立。所有任务的检测先保留在独立 `unresolved_membership`；集合任务（含 direct）及搬运路线由现有 `assess_task` 的同一次 JEV 问题按原始来源、数量、子集和排除条件给出 `required/excluded/unknown`，direct explicit 单目标由 `identify_target` 确认唯一成员；direct inventory 单目标也先通过 assess_task 区分任务成员和环境。仅 `required` 进入任务 `objects` 并编号。其他可见物体继续保留在实测观察/障碍中，`unknown` 不冒充成员或完成。未定成员的新帧/语义证据改变后允许 JEV 重新核对；相同证据不会反复开启判断。程序不按颜色或路线猜测成员。
- 目标选择与完成判断都以初始清单为范围；清单外新检测是障碍。JEV 按原文判断数量/组合/路线要求是否完成；保留的初始位置不是已完成物体还在原地的证据。
- 场景记录实际 RGBD 环境层、RANSAC 桌面 cuboid 和实例体素层。场景 token 与观测帧和清单版本分开。
- 三种路线：盒子→桌面、桌面→盒子、盒子→桌面→另一个盒子。第三种逐个完成两段，同一 ID 不变；第一段标为桌面中转完成，第二段才进入最终完成清单。默认固定黄色桌面区中心 `[0.38, 0, 0.60]` 米，大小 20×20 cm，位置仍通过 RGBD 识别；两个臂的位置 IK 均可达，实际轨迹另行检查。
- 目的地选择明确提供当前阶段：去桌面只允许 marker；第二段只允许 bin。仅当初始可见点在一个盒内的 XY 比例达到 50%、且该盒唯一时，才排除这个明确来源盒；轻微投影重叠不能排除其他盒子。JEV 决定具体目的 ID，运行端再次校验。已有阶段完成记录的 ID 不得重枚举，以免丢失第二段。
- 每轮 grasp 前：双臂到配置观测位姿 → 新帧 observe_geometry → 按清单选定当前目标 → build_scene(selected)。只排除当前目标，其余物体、盒壁、桌面和自碰撞保留。不要求三个相机同时看到同一物体。
- place 验证后，先由 JEV 的 assess_task 判断是否完成；未结束则使用现有地图回观测位姿，分析新帧并重新建图。只有第一次没有地图时才建立 observation 运动地图。回程复用不允许下一轮 grasp 复用旧地图。
- 2026-10-15 最新约束：物体在配置观测位姿应可观测。新地图只用当前 RGBD，不实现完全不可见盒内目标的历史/预测体素兜底。已放物体若在当前帧未关联到，返回 placed_object_not_observed 与缺失 ID，由 JEV 决定补观测；不当作空位或完成任务。任一相机的有效测量即可，不要求三路同时看见。
- 抓取结束并确认持有后 attachment；plan_place 的接近与放置保持 attachment，释放后 detach，lift/退回为空手。释放保持抓取 roll/pitch，只搜索 yaw。
- 执行臂初次由 evaluate_reachability 检查目标中心及目的中心的无碰撞、无姿态约束位置 IK，再由 JEV 选择。同阶段所有目标固定同一臂；两段路线第二段可另选。用户明确指定臂则直接使用；真正抓姿和路径仍需规划器验证。
- check_scene_changes / update_scene 仅保留旧 direct 模式兼容，三种搬运路线不使用增量快路。OpenAI 扩展本轮暂缓，基本流程不能依赖它。失败恢复仍由 JEV 决定。

## 观测技能的边界

| 技能 | 一次调用的产物 | 选择依据 |
|---|---|---|
| observe_scene | 固定头部分析、清单关联与编号 | 初始发现；搬运后的剩余物体/盒子核对 |
| observe_geometry | 同步帧实测几何与 ID 对应 | 双臂到位后；可先分析清单再选目标 |
| observe_result | 已执行动作后的图像与反馈 | 结果证据尚未取得或需要新的结果帧 |
| check_scene_changes | expected_only / unexpected / unknown | 已完成搬运，比较固定头部前后帧 |
| inspect_scene | 已有图像的语义或变化解释 | 可见像素足够，算法仍有明确歧义；由 JEV 选择 |
| move_to_observe | 配置双臂位姿运动及新 capture | 三种路线每轮抓取前；place 后使用现有地图 |
| build_scene | RGBD 碰撞图 | 初始运动地图；每轮抓取前在观测位姿重建 |
| update_scene | 搬运目标层变换/新目标排除、新 token | 保存已完成搬运层；仅背景有效时允许绑定下一抓取目标 |

一个相机提供有效几何即可继续评估抓取；这不是“完整看到物体”或规划必定成功的保证。三路深度可融合各自可见环境，但每一路只能贡献自己的实际首个深度返回。自动搜索最佳观测位姿尚未加入；移动技能使用配置位姿。

失败后的补观测、重试、暂缓和停止始终由 JEV 选择。程序只校验契约、版本、碰撞和次数预算；拒绝后不自动替换技能。暂缓后先处理其他目标，最终报告未完成项。

调用在执行前因前提不足被拒绝，不计作抓取/放置失败；JEV 收到未满足项后重新选择。连续 8 次无效选择结束为待处理。同一图像、掩码、参考帧及目的已有辅助结果时，不再次执行视觉 skill，错误结果也算已分析输入；新图像或新掩码仍可分析。OpenAI 适配器另外保留缓存和全任务 8 次请求预算。

机械臂到观测位姿后，旧点云就绪记录和旧变化比较不再当作当前证据，新照片明确标为待分析。决策上下文省略成功运动的重复轨迹和阶段关节数组，完整数据保留在日志中；数值显示保留六位小数，小于 1e-6 的非零值不舍入为零。当前验证结果与最近 verify 事件完全相同时，事件引用当前 `verification`，保留完整逐相机未知原因、身份缺口和帧标识一次；不同验证结果仍分别保留。算法原始输入不变，失败、未知和恢复预算及完整精简技能目录保留。集合完成判断只接收任务、清单、当前观测与语义证据；下一次运动所需地图是否有效不撤销已验证完成的物体。

## 2026-10-13 历史关联评分（新优先顺序待重新评分）

固定规则在 MuJoCo 实际 RGBD、在线 SAM3 数据上评分，物理真值只在感知结束后给独立评分器。40 段留出序列、776 次跨时刻机会：接受 757 次，正确 757 次，错误 0，未知 19 次（2.45%）；可判定且当前检测到的 738 次均正确。440 帧预期 880 个物体中检出 856 个，故关联覆盖率不能替代检测召回率。此数据包括两种颜色/相同工件、5 cm 中心间距、小位移和大位移，不代表任意遮挡或真实相机。

另 10 段留出序列逐相机独立标注，324 对接受合并的相机掩码均对应同一物体，未发现错误；不能用融合后多数标签冒充此指标。该组复用了相同场景生成种子，不与前组相加冒充独立样本。报告为 `data/observation-inventory-20261013/association-temporal-report.json` 和 `association-camera-report.json`。这些有限样本的 100% 不是总体保证，完全相同物体在不可见期间互换仍不可恢复物理序号。
