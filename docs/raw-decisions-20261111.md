# 完整视野与视觉判断

当前输入范围和身份链以 [全场景实例关联](rgbd-grounding.md) 为准。Responses、SAM3、Decisions 与建图保留完整相机视野；工作空间仅用于数值可达性，不裁切物体。历史 RGBD 恢复原始保存像素，不重新应用可达掩码。

Decisions 每个 HTTP 请求只有一题，按概率最大项选择，confidence 仅归档。平分、拒答和 unknown 保留未知；有效 no/unknown 不反复重问。每张图说明相机、采集、代次、时刻、当前/历史角色和坐标范围。细节 RGB 保留原像素，不画标签遮住主体，二值掩码使用同一裁剪坐标。

程序处理同图近似重复、唯一且双向充分的同步深度对应、同次已确认参考复用、数值关系、可达性和已知状态恢复。Decisions 处理部件归属、歧义对应、新时刻重识别、必要的视觉属性和支撑/包含关系。FoundationPose 按需提供已知 CAD 位姿证据，缺少它不等于身份无法关联。

verify_grasp、verify_place 与终止收尾读取同次实际夹爪反馈：全开为空、中间位置为持物，只有全闭才用当前 TCP 附近原始 RGB 判断材料存在。局部投影失败时使用完整腕图，不依赖 SAM3。抓后身份来自一致的连续执行记录，明确不是新的视觉身份核验。

放置结果题使用当前三相机、释放前图及日期参考，选择直接成功、执行证据推测成功、失败或未知。控制台小区域约束实际释放位置，不当成最终视觉落点框。持物、释放反馈、身份和回执各自保留真实来源。

旧版本验证记录仍位于 `data/runs/raw-decisions-20261111` 和 `data/runs/workspace-visual-policy-20261111`；这些历史结果不是当前合同，也不证明本轮完整任务成功。本轮证据见 `data/acceptance/full-frame-association/`。
