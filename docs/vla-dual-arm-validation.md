# VLA 双臂起始、右侧产物与 5mm 验证

2026-10-27。最终代码已部署到本项目的 MuJoCo 与 cuRobo 服务。修改后连续两轮单物体完整实验成功；这不是任意场景成功率的证明。

## 当前配置

- VLA 起始角度：A `[-86,76,88,-90,2,14,-24]°`，B `[106,61,-113,-78,27,36,37]°`。`prepare_unpack` 同步规划、碰撞检查、执行并核验两臂；效果前再次核验实际反馈。已删除单臂/空闲臂保留当前位置的准备选项。
- 黑色产物中心在世界 XY `(0.44,-0.30)m` 的 `4cm×4cm` 正方形内随机采样。该区域不可见，与网页配置的 VLA 输入 XY 分开。保留桌面支撑及右臂位置包络检查；精确生成位置不进入模型、清单或规划。
- 普通障碍硬净距默认及当前持久配置为 `0.005m`。释放高度与软激活距离独立。修正名义放置可达预筛选混用硬净距与释放高度的问题。
- 保留先 lift、再核验持物、最后 attachment 的顺序。首次 lift 检查机器人、双臂、环境、自碰撞与关节约束，不声明检查了携物扫掠体积。
- 修正稳定但越限的夹爪角度被当成持物证据的问题。闭合阶段直接报告 `gripper_position_outside_authored_limits`，记录实际值、上下限和命令；未放宽原有 0.0001rad 数值容差。
