# Luna 场景所有权、镜像与碰撞模型审核

本文保留场景、镜像和碰撞模型的历史审核证据。当前入口为 [Luna](http://127.0.0.1:8350/) 和同一工作台的 [仿真场景面板](http://127.0.0.1:8350/#scene)。当前独立启动和场景通信说明见 [Base 接入](base-integration.md)。

## 当前场景边界

- Luna 完全管理物理场景：长方体、球、圆柱、胶囊、椭球、CAD、常见/自选颜色、数量、位姿、质量、逐物体重力及固定状态。同一个 CAD 可创建多个不同颜色实例。自由物体关闭重力后仍可被推动；固定与无重力是不同状态。
- Luna 直接向 Simulation 提交通用网格与配置，Base 不转发、不依赖 CAD 库；Simulation 验证、编译并持久化最后成功版本。Base 自己的“孪生场景”只影响其 Viewer。场景管理接口与任务感知/规划隔离，物体真值不进入任务算法。
- Luna 根据配置的 Base 地址读取真实运行身份，自动区分真机/仿真。真机与身份未知时前端与 Luna 后端禁用物理场景写入；无独立模式开关，也不按 IP 前缀猜测。
- 建议按真机/Simulation → Base → Luna 在各项目手动分别启动。三个项目均可独立启动；Luna 在 Base 离线时显示连接状态，只有任务执行要求 Base 身份与设备就绪。网页启动不触发机器人连接或使能。
- 仿真场景写入要求机器人空闲且双臂取消使能；保留机器人关节/执行器状态。等待新场景编译并渲染期间，RGBD 不返回旧场景缓存。
- 有限轨迹、关节和夹爪命令不依赖 Action Stream。FK/自身点云剔除继续使用固定 cuRoboV2-Fast 公开接口。录像仍归 Luna。

检查覆盖了实测、观察位和全零位三种双臂姿态，各含 21 个等分夹爪位置及 2 个非对称端点，共 **69 组**。范围 0–0.8281179735 rad，自碰撞与关节越界代价均为零。485 个 SDK 文件哈希与提交 `42498cf4e7d0d6fbd4ef9fbcec1243c00c888a83` 一致。

三相机重新逐三角形审核：立柱含头部 19 球、左腕 12 球、右腕 16 球；428,106/21,734/21,734 个细分三角形均被覆盖，保留 0.5 mm 余量。11 个未改动的本体网格文件哈希与既有审计一致。
