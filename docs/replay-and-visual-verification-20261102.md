# 视觉判断与阶段回放（2026-11-02）

用户要求：只在有视觉缺口时换观测位姿，解耦 CAD/永久身份/支撑关系，显示初始 Responses 框和实际阶段碰撞地图。沿用三相机、CAD/OBB/cuboid、一次初始 Responses 及 Decisions 恢复；不新增体素、机器人射线过滤或释放后几何重建。

## 证据与实现

P51 的身份阶段并非单次模型耗时：事件222为4.821秒，含完成物体对应1.028秒、清单对应1.584秒、同帧澄清1.993秒。事件542为5.575秒，三次HTTP共3.989秒，其余是图片/测量对应处理。因此不能把整个阶段算为 Decisions 推理耗时。

后续观测的 associate_inventory/verify_transfer 直接询问互斥身份谓词，恰好一个>=0.8且其他<=0.2才接受。初始同帧关联保留有界澄清：只对未决候选补充主体图和已经确认的当前身份锚点，不重拍、不重问已接受的候选。初始已有同帧对照图时不额外加入全尺寸主体图。已完成物体核对仍是独立事实，其当前身份锚点供后续对应使用，不能无条件并行或假定仍在原位。identity_resolution 保留总计，并增加准备、流水线墙钟和当前线程CPU时间。几何建模另行计时。

verify_place 只使用当前三相机 RGB、真实夹爪反馈和已绑定目标参考。普通整盒放置判断入盒与是否仍夹持。指定区域或语言子区域增加独立 placement_near_target，使用已知区域、支撑高度和当前外参的参考投影；它不是实物边线或落定物体测量。允许定性误差，不要求所有像素在投影内。不调用 SAM3、OBB 或 FoundationPose；释放规划和执行端点的数值检查仍保留。目标区域在所有相机外或被遮挡时保持 unknown。

恢复请求用三个独立谓词询问 recovery_not_visible / recovery_cropped / recovery_occluded，允许同时成立，不强迫在重叠原因之间作互斥选择。任一当前视角满足所需信息时，其他视角的缺口不能独自授权移动。仅至少一个谓词通过原有0.8门槛且确实影响当前操作时可提出观测移动；低置信本身、CAD不匹配、服务/规划失败不能授权移动。诊断与恢复选择在一次请求中，动作前检查采集版本与 epoch。同一失败、采集和epoch的诊断（包括unknown）被复用，拒绝一个能力不能触发重复诊断以追求置信度。正常任务要求的交付后配置回位不作为视觉恢复。

初始 Responses 的原框在原始输入RGB上单独归档，永久ID来自编译绑定但身份仍标记“未核验提议”。SAM3分析不会覆盖该版本。回放的“Responses 初始参考框”直接定位此版本。

每次 build_scene 从已经发布给规划器的 collision_scene 导出不可变快照。保存当时的 CAD 位姿、OBB/cuboid 和 enabled 状态，附 scene_token、观测ID、generation。几何服务只通过原建图响应传递快照，不写文件；实验写线程将静态CAD网格按已有网格哈希保存到实验自包含资产目录，同一网格在算法原始记录和阶段记录间共享，不重复HTTP获取最新场景。回放按阶段选择，不读取实时地图。旧实验若未归档则明确显示不可用，不伪造历史地图。
