# 感知决策、碰撞可信性与实验回放

本轮承接用户已确认的执行任务，处理后续九项要求。失败恢复最终由 JEV 判断；OpenAI 仅在 JEV 明确调用时提供图像语义或执行结果证据，不生成动作或替代恢复判断。保留完整 skill 目录与执行前契约校验。

## 决策与速度

- 删除 verify_grasp / verify_place 的自动 OpenAI 兜底。unknown 返回 JEV；由其选择新观测、视觉辅助、重新验证或停止。未知不自动等同失败，也不消耗一次抓放重试。
- JEV 根据当前识别、可见性、帧编号、已用辅助和预算决定是否求助，而不只依赖原始指令的复杂程度。遮挡没有像素证据时优先新视角；一次请求覆盖同帧全部相关实例与关系。
- JEV 选择 observe / build_scene 的时机。输入明确提供观测帧、场景帧、检查点、失效原因和已知碰撞模式。build_scene 的目标接触 / 持物 / 完整观测策略由 JEV 显式选参；程序只验证证据和实现对应几何，不自行解除桌面、盒壁或自碰撞。
- 优化以现有真实 87.74 秒参考任务为基线，分项报告。优先不改变结果语义的连接复用、同帧数据缓存与重复序列化；规划候选降量和安全余量缩减不作为隐性优化。

## 碰撞球与 RGBD

- 机器人球数量至多 350（附着物预算单列）。恢复中心轴向模板和左右臂/夹爪映射对称，优先拆分大球，禁止无覆盖证据的统一缩半径。
- 以同一 CAD/代理表面采样比较覆盖缺口、突出量、夹爪局部高度切片；再做 FK、自碰撞、桌面和既有路径校验。不能以整个夹爪 AABB 直接宣称某盒口机械不可达。
- 保存三个相机真实渲染深度的遮挡回归证据，明确区分校准/自身关节反馈与环境特权几何。未看到的表面不能生成测得点；由 RANSAC 推断的桌面 cuboid 必须标注推断来源。
- 当前未观测空间检查没有接入运动校验。这轮透明显示这一限制，不盲目启用会把自身遮挡和所有未扫描区域当障碍的全域封锁。
- 工作台显示实际规划图里的体素及桌面 cuboid，并标明帧、来源和测得/推断层；不可从简化展示点云重造一份假碰撞场景。

## 回放

- 已完成 saved/pending 实验可移入配置归档根下的 .trash。禁止删除仍录制/编码/导出/传输中的记录，限制合法 ID 与路径，界面确认具体实验。无需实际删除任何用户记录验收。
- 以水平阶段子图呈现实际执行，保留成功/失败路线、调用身份、JEV 证据、时间、详情和视频定位。重复调用可折叠但所有事件可达；不虚构未执行策略分支。SVG/PNG 与交互图同源布局，支持缩放/平移。
