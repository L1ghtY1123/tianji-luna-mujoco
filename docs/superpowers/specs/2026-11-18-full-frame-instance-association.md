# 完整视野与一致实例分组

用户已授权继续重构，并明确取消工作空间像素掩码、解决重复分割。本规格在上一轮验收失败（0/10）的基础上实施，不把此前通过的静态检查当成可靠性证明。

## 边界与决策

- Responses、SAM3、Decisions、身份参考和建图消费完整相机视野。有效深度与机器人自身点云过滤继续用于测量；离线工作空间仅用于可达性，不裁切 RGB、物体轮廓或历史参考。
- SAM3 输出是掩码假设，不是实体清单。先处理同图重复，再解决一个物体多个可见表面的归属。容器及其内容物必须分开。
- 不采用沿相机顺序占用候选后补救的旧分组。所有跨相机选择面对相同、未被占用的候选集合，最后统一检查双向对应、传递关系及每相机实体唯一性。矛盾组件保持 unknown，不新增永久 ID。
- Decisions 不介入程序可以确认的精确重复、近似重复假设整理、唯一且双向充分的同步深度对应、同一冻结采集已确认参考的复用及连续执行身份继承。物体部件归属、有竞争的跨相机对应和独立新时刻的重识别交 Decisions；均提供完整场景和精确掩码，遵循单题及概率最大项合同。
- FoundationPose 不是身份前提。当前像素去重和明确深度对应不调用它；歧义对应可按需请求已知 CAD 位姿证据。未知 CAD 或配准失败不阻止其他证据关联。后续已知 CAD 抓取仍需当前有效位姿。
- 相同模型、颜色或位置都不能单独确认永久身份。跨时刻移动不因旧 IoU 低被判为新物体。注册独立于任务选择，保持原事务与版本约束。

## 取舍

纯阈值关联不能解决桌边、盒壁和盒内物体的物理归属；全部候选两两发模型请求则放大调用成本和矛盾。采用数值整理掩码、同图实体归属、同步双向对应和统一约束检查。近似掩码去重只整理同一图像中高度重合的分割假设，不能依据框包含关系合并物体。

## 验收

保留跨工作空间边界的完整 RGBD 和实例轮廓；重复文本/框分割不新增实体；相互包含但掩码不同的盒子与内容物不被 NMS 合并；不相交的桌面片段可归属于同一实体；输入顺序不改变一致分组；多对一、循环和冲突不生成 ID；无 CAD 及 FoundationPose 失败仍可关联；同次已确认参考复用不调用 Decisions 且不伪造模型记录。历史回放先恢复原始完整视野，再评估分割、分组和 ID，不能把已裁切图当成新的完整视野输入。通过后使用实际入口验证，并独立报告未通过的任务环节。


场景段是检索边界。接受简短清单、自然语言位置与支撑描述、未知数量 n 和实际 CAD 仓库代号。重复框的类别来自其声明引用。三维关联需要比较当前同次证据，跨时刻用有日期的参考和操作记录。桌面数量冲突优先检查实测支撑；无法由几何解释的超额组不登记。
