# RGBD 身份与操作核验实施计划

本计划按用户 2026-11-10 的八项要求执行，采用 executing-plans 在当前项目内实施。

## 目标与接口

复用每次授权采集的 RGB、深度、标定、掩码以及动作回执。几何模块输出带采集绑定的测量证据，Decisions 处理身份、遮挡和复杂关系的歧义。Graph 继续控制观测及恢复时机。抓取默认 CAD 10 mm、OBB 30 mm。

## 实施顺序

- [x] 工作空间过滤。workspace.py、perception.py 与采集入口实现工作空间与已登记物体当前候选掩码的并集。原始图像仅用于同次采集的候选恢复。登记仍要求工作空间准入或已有身份。
- [x] 身份对应。identity_geometry.py 统一历史及同帧三维表面投影，计算可见性、深度一致重叠、遮挡与矛盾像素。identity_correspondence.py 接入双向当前候选对应与身份冲突检查，歧义交给单题 Decisions，参考在确认后提交。
- [x] 抓持核验。grasp_verification.py 使用实际闭合 TCP、当前 FK、抓前几何与当前点云比较预测位置和位移，提供误差与支撑分离证据。清晰数值结果直接使用，歧义交给 Decisions。
- [x] Lift 预检。在已有携物检查与支撑脱离接口内检查完整携物轨迹，允许起始支撑接触，检查其他障碍及抬离后的支撑间隙。正式 attachment 保持在 Lift 和核验后。
- [x] 支撑与放置。复用已测容器局部区域、桌面支撑平面，提供点云空间关系。释放核验比较释放前授权观测与放后观测的盒内表面变化，并绑定执行记录，结合空手证据处理相同工件堆叠。
- [x] 确定性选臂。使用现有数值可行域与运动距离排序，保留复杂任务约束的 Decisions 判断。
- [ ] 同步技能契约、开发说明与控制台参数。静态检查、构建、冻结输入正反例、部署哈希检查、完整双物体仿真验收。

## 验证边界

重点覆盖相机移动、物体移动、容器遮挡、同色多实例、旧 RGB-only 参考、无效深度、工作空间边界、薄件、堆叠和支撑接触。每项先用确定性探针复现旧行为，再验证修正。项目按当前约定使用 data/runs 下的复现记录及现有审计入口。

变化检测同时记录当前深度相对历史表面的新增、消失、遮挡和可比较区域，单纯采集差异保留为歧义证据。运行期间的观察继续通过技能契约授权。
