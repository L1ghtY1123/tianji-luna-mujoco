# Decisions 输入精简与判断解耦

## 目标

身份问题直接绑定候选主体、图像标签和清单描述。每个相机和时刻使用一张完整标注图。程序侧保留来源验证与审计，模型侧只接收本次判断需要的事实。

## 实施与验收

- [x] 替换身份展示和问题构造，删除重复裁剪、独立掩码图、指令拆分与历史协议入口。
- [x] 身份关联、当前可见性、清单完整性分别请求与解析。各自绑定原始请求，语义失败不撤销其他已确认结果。
- [x] 用冻结失败请求检查正例和错误匹配，验证同采集、多相机和拒答处理。历史跨采集样本仍有未确认身份，完整产物链条待全任务成功验证。
- [x] 运行静态检查、正常入口和完整仿真尝试，核对实际图片数、token、成功与失败原因。
- [x] 同步 Ubuntu 并更新当前协议文档。保留历史实验，生产入口不加载实验脚本。

本轮沿用 Responses 生成 graph 和 Decisions 选择已有分支的边界。阈值、CAD 选择、几何及运动验证由各自现有模块负责。
