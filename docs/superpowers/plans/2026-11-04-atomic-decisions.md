# 独立 Decisions 判断与身份时序

本轮依据用户十二项要求执行。单次模型请求只有一个有类型问题，复用冻结采集与已返回的答案。模型输入使用统一 C/R/ID 标签，程序保留永久 ID、来源校验和完整审计。

- 在公共 HTTP 边界拆分问题，保留逐题请求来源、原始回答及转换原因。
- 同帧跨相机对应使用 RGBD 投影证据及独立视觉问题。跨时刻身份选择使用当前主体、清单参考及真实动作历史。
- 清理重复状态、重复图像和含混指代。检查一件、多件和多相机候选的标签一致性。
- 明确 Responses 根据技能前提编排主线、顺序和恢复分支。图执行与清单显示顺序分开。
- 通过接口回归、冻结请求、不同物体数量的真实编排和完整仿真尝试验证。同步当前契约与 Ubuntu，报告未通过项。

## 已验证的行为

- HTTP 边界拆分为单问题请求，逐题证据绑定原始请求。缓存保存原始回答，解析器获得副本。
- 1、3、7 个身份候选通过离线协议回归。覆盖稀疏候选编号、模型低置信度、单问题传输、解析缓存隔离、跨相机对应证明与 graph 自主顺序。
- 同时刻跨相机判断输入两张相关 RGB、标定世界坐标和相互深度投影重叠。独立永久身份判断使用主候选、已确认同刻视图及动作历史。
- 清理旧身份概率矩阵和依赖矩阵的诊断。公共输入使用 C 标签，选择参考 R 标签后按显式映射保留永久 ID。
- 默认 explicit 顺序允许 graph 选择任意待处理成员。用户明确要求 inventory 或 nearest 时继续验证该顺序。

## 未通过项

来源角色选择在三物体冻结案例中，精简输入后的 confidence 为 0.63，补充选项含义后为 0.70，仍低于事实选择门槛。移除 RGB 的对照实验为 0.41，因此当前请求保留 RGB。最后一次完整实验的来源判断为 0.98，但目的地为 0.71。模型已经选择具体实体，程序仍会将低置信度事实选择标记 unknown。

身份输入的针对性改善已验证。任务来源/目的地语义绑定尚未达到可靠验收要求，抓取规划、释放核验及跨时刻动作历史的整链路验证仍未完成。
