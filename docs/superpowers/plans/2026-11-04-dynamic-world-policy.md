# 动态清单与循环任务图实施计划

用户已选择动态物体清单、全局永久 ID 和循环选择目标。由当前会话按 executing-plans 逐项实施，遵守 AGENTS.md 的单 agent 约束。

## 目标与边界

Responses 根据当前任务和技能在线生成图。物体数量与图拓扑分离。清单记录实例、观测、操作历史与加工谱系，图显式选择当前目标并执行有限恢复。物体 ID 使用从 1 开始的永久数字，重新观测和新任务均复用已确认的同一实例。新增实例只分配一次，退役 ID 保留历史。

用户最新要求取代旧的每个初始物体必须拥有独立子图、初始清单封闭的限制。三相机融合、自身过滤、单题 Decisions、CAD/OBB/cuboid、数值碰撞检查及最终机器人位姿验收继续作为接口要求。OBB 尺寸变化判断保持删除。
