# JEV 选择视觉调用与实验回放

用户已批准上一轮视觉方案，并明确选择“外层由 JEV 选择调用及用途，技能内部固定执行”。本计划在已有候选工作树继续；不切换生产机器人后端。回放界面在兼容性测试通过后独立发布。

## 实现约束

- JEV 在技能参数选择阶段，为该技能将要分析的具体观测选择 Decisions 用途；无选择不能发送图片。初始化、固定清单关联、放后区域验证分开表述。地图复用不重复请求。
- 场景限于指定桌面、其上的盒子及内容物；已知夹持对象保持身份。全部实体与搬运子集共享全局 ID 和冻结编号。
- 输入保留原始 RGB，同时附候选编号、初始确认 ID、目标区域和槽位的轻量标注；未关联候选不猜 ID。无有效掩码不能当成物体消失。
- 放后验证绑定实际 region_id/slot_id；几何仍来自 RGBD。每次真实请求归档图片、问题、回答、耗时与失败信息，不归档密钥。
- 回放提供观测图片入口、相机和观测时机标签、带标注图；执行图改为便于横向浏览的布局。
