# CAD 身份与放置收敛

用户要求：同一永久 ID 只持有当前 CAD 或 OBB，桌面 cuboid；三个相机提供同一物体的观测，不创造新身份。已知 CAD 用对应臂离线抓姿，未知 OBB 用 GraspGen。一次 Responses，运行时 Decisions 与技能，保持现有 graph 接口。

## 改动与验证

1. `inventory_map.py`：当前成功观测的 OBB 替换原 OBB，不累积新旧角点。未观测/局部范围外实体仍保留历史来源，动作失效仍失效。更新 `test_hybrid_map_lifecycle.py`，先确认现版本失败。
2. `cad_perception.py`：确认模型绑定按 generation/永久 ID 缓存；提供经过几何验证的模型尺寸供身份必要条件检查。相机按当前有效掩码深度数量排序，同一相机掩码合并后只尝试一次，先尝试主视角；位姿须通过全部已关联视角和全部当前点的原校验。仅数值位姿不通过时尝试下一视角，不因服务/来源错误循环；至多三相机，不平均位姿、不换 CAD、不发布冲突结果。新增多相机测试及真实冻结服务验证。
3. `demo_perception.py`/`visual_inventory.py`：在已有当前容器追踪锚点和已验证 CAD 模型存在时，使用两掩码世界点 AABB 的最小分离距离与 CAD 最大直径比较。距离大于直径加原两侧容差时，排除该不可能的同实例选项；仅排除，不自动指定其他 ID。未知模型、历史位置或无当前锚点不参与。把数值原因提供并归档给 Decisions，禁止 parser 接受已排除选项。用 B6 真实错误范围和合成正/负/缺证据测试。
4. `runtime/controller.py`：目的地实体选择只保留一个同时引用原始指令、永久 ID 和当前证据的语义判据，删除与其重叠的第二次身份题；配置区域授权仍校验。具体子区域/相对位置由现有放置区域和候选语义核验负责，原数值门保持。先对 A10 冻结输入作一次正题/右盒反例诊断；不根据回答改门槛，不重复采样选高分。
5. 放置入口沿用当前 `perceive_placement_zone -> resolve_placement -> plan_place` 接口：原指令规定范围、有限 XY、当前夹爪/持物、工作空间、IK/FK和完整几何间隙。该顺序是技能数据依赖，任务图仍由 Responses 编排。验证普通表面、容器、相对位置已有测试，实际运行左臂 CAD 入盒及未知物体桌面场景；记录真实失败，不能用冻结结果替代完整验收。
