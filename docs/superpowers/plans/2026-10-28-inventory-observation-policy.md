# 清单观测与证据回放实现计划

**Goal:** 使三路候选/参考/身份结果可追溯，并将初始观测不确定交给 Responses 编排的图处理。

**Architecture:** Responses 产生候选清单与整任务图；清单是图的数据状态。observe_scene 与 confirm_inventory 均为显式节点。执行器不再在图外强制观测/绑定。Decisions 的 unknown 保留为证据不足，不冒充任务不可能。

**Tech Stack:** Python/Pydantic、原生 JavaScript、现有 Decisions/Responses、MuJoCo。

**Spec:** 用户本轮请求及 AGENTS.md / luna-policy-isolation。

## 约束与验收

- 不改阈值换成功，不把 SAM 候选自动当永久 ID；未知辅助视角不伪造结果框。
- 参考框与候选图读取真实请求归档，展示来源、去向、调用及问题。
- 仅模型编写补观测分支；移动仍需当前实测地图与数值碰撞检查。
- 清单确认前不允许目标执行；数量和排序在确认后绑定，循环读取确认后的选择。
- 已完成对象和动作不得因恢复重放；最终检查失败仍保留未知，不宣称成功。
