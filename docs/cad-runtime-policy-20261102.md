# CAD 与放置的当前策略（2026-11-02）

生产资产只从独立 `CAD/` 库读取。`cad/` 保存原始文件，`grasps/` 保留与原始模型哈希绑定的左右臂抓姿，`runtime/` 保存统一的运行模型清单、标准坐标网格、预览和 FoundationPose 简化网格。蓝盒配准网格 2000 面，黑色工件 1999 面；原始模型和离线抓姿不变。项目内 `resources/cad` 仅保留可移植测试/仿真基线，未设置 `LUNA_CAD_ROOT` 时才读取，生产容器明确设置 `/opt/cad`。服务 registry 在项目 `data/` 是可再生成缓存，不是另一个 CAD 库。

永久 ID 标识场景中的实例，asset_id 标识库中型号。两个相同盒子可以共享 asset_id，但 ID、位姿、任务记录独立。已确认 ID→型号无需每帧重做匹配；新采集仍更新当前位姿。加工产物使用新 ID 并保留输入输出关联。简单清空篮子任务不必依赖永久 ID，本程序保留它用于抓姿、持物、加工和完成账本。

三个相机先提供已关联到同一 ID 的掩码。按掩码内有效深度数量选择一个相机，把该相机 RGB、深度、掩码和内参给 FoundationPose，外参把输出转换到世界坐标。直接采用有效的源模型/坐标/采集绑定一致的结果，不做后续点云、轮廓或深度射线吻合检查，不做 ICP。结果明确为用户授权的精度假设，不宣称额外测量验证。CAD attachment 直接覆盖模型体积，保留既有不确定度和净距，不再要求点云残差扩张；仍在 lift 成功、持物确认后建立。

普通区域按二分层级从四分开始，每次沿下一轴分割得到八分、十六分。每层中心补偿抓取偏心并检查完整持物足迹范围。Decisions 返回候选 ID，不输出自由文本坐标。已授权整个区域时只需选择操作提议，历史 RGB 明确标记，不重复观测；有相对方位/指定子区等附加语言要求时，用当前图像上的候选足迹逐项判断。先选 XY，之后才求 Z：从硬净距及既有 0.1mm 跟踪余量起，以原有 1mm 间隔递增，在最大释放间隙内找到第一个场景/夹爪/attachment 无冲突且工作空间和持物 IK 通过的端点。失败换下一个候选或下一层。最多 28 个 XY，通常第一个可行就停止。工作台“指定/设定区域”使用配置 XY，阻塞时不漂移。

plan_place 继续规划接近、放下、撤离三段轨迹。几何无碰撞、位置包络、给定姿态 IK 和整条路径可行是不同检查，均由数值程序完成。

观测按场景/命令版本、动作 epoch 和关节/夹爪反馈判断能否复用，时间超过10秒不再单独触发新采集。相同采集与身份输入的成功分析可复用，失败身份分析不能靠重复原位采集重试；变更视角或身份输入由 graph/Decisions 选择。没有隐藏移动或补图节点。
