# 任务区域与物理场景

物理场景完全由 Luna 工作台的 `/#scene` 面板管理，详见 [Base 接入说明](base-integration.md)。支持 box、sphere、cylinder、capsule、ellipsoid 和 CAD 网格；可批量创建并独立修改每个实例的颜色、位置、姿态、质量、重力和固定状态。CAD 保持库中尺寸，实例可以不同颜色。无重力自由物体仍有碰撞和惯性；固定物体没有自由关节。

Luna 转换 CAD，并通过独立场景适配器直接向 Simulation 提交通用配置/网格，由 Simulation 编译与持久化；Base 不转发场景。Base 的孪生场景编辑与物理场景完全独立。真机或未知模式禁用此面板及所有物理场景写入。场景写入要求仿真空闲、已连接机械臂取消使能；Simulation 自己将场景应用与控制命令互斥，新场景成功渲染后才能再次采集任务 RGBD。

`resources/demo-config.json` 只保存任务释放区域和观测姿态引用，不是物理实体。坐标为机器人前方 +X、左方 +Y，长度单位米。配置页显示毫米，传输使用米。应用物理场景会恢复全部物体的配置姿态，保留机器人关节状态；重置任务不修改物理场景。

场景对象位置、ID 和 CAD 选择不传入任务算法。物体记录与碰撞场景必须从 RGBD、Responses/Decisions、SAM3 和 FoundationPose 建立。额外障碍通过深度建图。手工摆放不证明物体被识别，也不证明规划安全。

旧实验场景和录像保留在归档中，不作为当前配置或模拟拆包效果运行；没有实际 VLA Provider 时加工能力明确不可用。
