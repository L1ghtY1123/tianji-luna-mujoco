# 减球拟合试验：尚未达到替换条件

当前运行模型仍是309球，文件 `resources/curobo/marvin_gui_dual.yml` 的 SHA256 为 `f617cfc7dcd382d7eda37e998392fe286212f01ab59c7bf7d5dcbbbda10f5197`。上次313→309只删除4个被其他球包含的冗余球，不能称为局部重新拟合。这次确实运行了8轮新的拟合，但没有将劣化候选部署为正式模型。

## 方法与结果

使用项目锁定的官方 cuRobo `curobo.sphere_fit.fit_spheres_to_mesh` / MORPHIT，SDK commit `8e734f3ced1df898990bcd92de40abce475907db`。未修改SDK、碰撞buffer、自碰撞忽略关系、关节限制。分别尝试整链网格、沿主轴切分网格、按腕部叉形结构切分网格，以及不同球预算、外凸惩罚和随机种子。左右臂仍按已有URDF映射保持对称。

| 轮次 | 方法 | 主要结果 |
| --- | --- | --- |
| 1 | Link4/5/7整链减少球数 | 对称装配可降至233球，但Link5的球并集外边界最大外凸从约2.95增到39.05mm；拒绝 |
| 2–3 | 整链提高外凸惩罚 | 没有同时解决覆盖和外凸 |
| 4 | Link2/4沿轴切成三段；腕部整链 | 仍有覆盖缺口，继续细分 |
| 5 | 三段臂结构与叉形腕部分别拟合 | 对称装配247球；Link2/4最大采样覆盖缺口从8.17/8.75增到15.41/12.51mm；拒绝 |
| 6–7 | 分段腕部提高外凸惩罚 | 没有得到可替换结果 |
| 8 | 按腕部叉形两侧壁及中间连接分别拟合 | 每个腕部Link由24减到16球，覆盖改善但外凸仍变大；拒绝 |

第8轮采用与当前配置相同的buffer比较：Link5最大采样覆盖缺口从10.57降到7.18mm，但沿局部Y轴的包围盒外扩从5.63增到17.24mm；Link7沿局部Z轴外扩从3.93增到21.69mm。覆盖缺口、轴向外扩与球并集表面的实际外凸是不同量，不能混作同一指标，也不能把采样结果当作完整表面保证。

目前没有证据证明这些低球数候选能在保持覆盖的同时减少保守碰撞，更没有可宣称的规划加速比例。当前309球模型本身也有残余外凸，本次未解决。继续优化需要对问题结构调整分区/球预算，并重新通过几何覆盖、外凸、对称性及规划回放检查；不能仅缩半径或用更少的大球替代。
