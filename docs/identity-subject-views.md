# 身份澄清中的 SAM 主体视图

身份 pairwise 澄清为每个本次仍被询问的当前候选统一附加一张主体图，帮助区分容器本体和框内其他物体。原有全部 RGB/JPEG、参考与标注图、问题及顺序保留；不重新采集，不增加 Decisions 调用。已接受身份继续沿用原回答及请求来源，不重新提问。该输入用于 `observe_scene` 以及 `verify_place` 内的 `verify_transfer` 身份测量，不自动确认放置或其他语义结果。

候选以当前澄清请求中实际保留的身份谓词为准：既包括展开的 `match_N_*`，也包括同帧对应仍保留的 `identity_N` predicate。两类混合或仅剩同帧谓词时均附图；已接受并移除的问题不会恢复，也不会为其额外生成主体图。

主体图来自同一候选的原始当前 RGB 和 `silhouette_mask`。使用分割完成、清单表面分配之前的 silhouette，不使用经过深度或物体几何裁剪的 `mask`。轮廓内原像素保持不变，轮廓外统一置为 `[128,128,128]`；灰色表示未呈现区域，不是材质、空闲空间或补全几何。图像不裁切、不缩放，以无损 PNG 编码；顶部另加 32px 白色标签，标出原 C 编号与相机。标题采用 18px Arial，可用字体缺失时使用 Pillow 默认字体；这只影响标签，不改变原图区域。

追加前检查 Candidate、相机、observation ID、generation、分割阶段、RGBD/标定与 silhouette 的形状、类型及 SHA-256 是否和原请求中的 `candidate_provenance` 一致。缺少或被改动的绑定返回 `visual_identity_subject_binding_invalid`；已有更早的代次校验仍可拒绝请求。包括新增图像在内超过原 128 图上限时明确失败，不能挑选部分候选呈现。原始数组仅在项目内显式传递，模型接收图像和可审计来源文本。

模型调用归档同时支持 JPEG 与 PNG：严格解码 base64，核对 MIME 与实际图片格式，并校验完整像素解码；按原始字节保存 `.jpg`/`image/jpeg` 或 `.png`/`image/png`，不重编码。回放通过归档文件的实际扩展名返回 MIME；按原字节及元数据可还原请求哈希。损坏、格式错标或不支持的图片仍明确记为归档错误，不伪称记录完整。SAM 主体图在回放中保留当前相机/观测来源与候选标签，区别于原 RGB 和候选外接框。

早期 JPEG 专用归档写入器遇到第一个 PNG 会中断该调用的 JSON/index 写入，可能留下前面的 JPEG 文件。C5 event639 的缺失调用及 B6 event390 仅留前 10 张 JPEG、在 4 张主体 PNG 前停止的证据与此边界一致。兼容修复保留原模型调用和机器人行为，不恢复已经丢失的原始调用记录；本地混合 JPEG/PNG、真实主体图构造入口、HTTP 回放与请求哈希回归已通过，实际部署后的归档完整性须另行核验。

SAM 主体图只是额外视觉证据，分割可能有误。它不分配永久 ID，不凭相机、位置、CAD 或颜色自动绑定，也不保证分割之外没有其他对象。未决候选仍须恰好一个身份概率达到 0.8，且所有其他身份不超过 0.2；冲突与模糊回答保持 unknown。未知辅助视角不进入几何；真正缺失的登记实体仍按既有覆盖前提处理。CAD 检索、FoundationPose、几何及放置核验保留各自独立检查。

冻结 C4 对照来自运行 `9279e28ae7d94fe783159b40f78d25bf` 的 fresh 身份澄清：13 张原 JPEG 与 37 个问题完全不变，对全部 8 个待问候选各加一张 640×512 主体图。一次实际 Decisions 调用耗时 1.775s、输入 28,235 tokens；C6 对左盒为 .99→1.0，对绿色为 .90→.04。按同一 parser 融合，绿色由 C1/C5、右盒由 C2、粉色由 C4、左盒由 C6 覆盖；C0、C3、C7 仍 unknown，未接受。原 C6 silhouette 与绿色、粉色 silhouette 的相交像素均为零，说明这次主体图提供了 bbox 无法表达的像素归属。

项目实现与冻结对照逐一比较：全部原图、问题、追加说明及主体图原始区域像素一致；跨主机标题字体可能不同。资料位于 `data/cad-obb-iteration-20261030/unknown-C4-identity/`，包括实际调用、`masked-comparison-cpu-fusion.json`、`production-subject-comparison.json` 与源码 SHA 清单。冻结身份覆盖及 CPU 回归不代表 CAD 位姿或完整物理任务验收；该版本实际任务由后续独立运行验证。
