# 观测目的规范

## 先确定需要什么证据

| 目的 | 需要的产物 | 不等于 |
|---|---|---|
| 场景发现/更新 | 当前可见实例、实测深度、任务范围内尚未看清的区域 | 已确定全部目标或已建碰撞场景 |
| 指定目标/区域几何 | 该对象或区域的实测点云、像素来源、缺失与关联证据 | 已有抓取解、已证明路径可行 |
| 动作结果采集 | 指定动作后的 RGBD 与夹爪/关节反馈 | 已判定动作成功 |
| 移动换视角 | 按明确位姿完成移动及到位采集 | 自动发现最佳视角或自动决定恢复 |
| 图像语义辅助 | 可见图像支持的身份、关系或结果证据 | 新测量、隐藏深度或运动命令 |

场景观察和几何观察可以共享一个 capture；区别是查询范围与输出用途。结果采集可复用执行 skill 已取得的动作后 capture。没有信息缺口时，不必把所有观测 skills 顺序执行一次。

## 三种操作必须分开记账

1. 已有帧分析：像素和深度不变，只增加分割、关联或语义结果。
2. 原位重新采集：取得新时间的 RGBD/反馈，机器人不移动。
3. 移动换视角：改变相机位姿，再取得新测量。

调用参数明确选择复用或新采集，不让 skill 默默回退。分别记录采集次数、分析次数、外部视觉请求次数、观测移动次数；同帧缓存命中不产生新观测。

## 相机可见性

采用所有可用同步 RGBD 的真实可见深度；某个相机没有目标掩码时，它仍可贡献环境障碍。任意相机测得的目标点云可以经标定转换给指定执行臂使用。不得要求执行臂自己的相机必须看见，也不得要求两腕或三相机同时看见。

相机数量只是来源元数据。补充观测的依据是具体证据缺口：未识别到、有效深度不足、实例关联冲突、相关几何过期、关键区域未观测等。一个或三个相机都不能单独证明数据充分或不足；未观测空间不能被当作已测得空闲。

## 什么时候考虑哪种操作

- 已有当前帧但缺某个对象的分割/几何分析：分析该帧；不会因此移动。
- 执行动作后只有旧帧，或需要新的反馈/时间证据：考虑原位新采集。
- 图像已经显示有足够相关像素，但语义含糊：JEV 可选择一次图像语义辅助，复用该帧。
- 固定遮挡、出视野且已用完同帧信息：报告被遮挡/缺失区域；JEV 可考虑换视角。再处理同一像素不能产生隐藏深度。
- 纯 IK/关节限制/服务故障：不能自动当作观测问题。规划无解也不能直接证明需要换视角。
- 同帧同问题没有新信息：返回缓存或 no_new_information；不自动重复调用，不强制 JEV 选某条恢复路线。

这些是技能的适用边界。JEV 仍选择下一步，程序只核验被选动作能否执行。禁止把表格直接改成固定恢复状态机。

## 观测移动与能力范围

移动前必须有本次路径可用的碰撞证据，目标本身也保留为障碍。初始建图不能依赖已经有抓取解，否则形成循环。缺少安全第一步的证据时报告受限，不能假定高处或机器人周围天然空闲。

固定预设位姿与自动生成位姿是不同能力。仅有预设位姿时，明确公开其局限；没有可用位姿就返回能力限制，不声称已搜索整个空间。只有当实际任务暴露固定视角解决不了的明确缺口，才据此设计、验证自动位姿规划。其输入应包含观测目的和相关区域，输出有限候选及可达/碰撞/预测收益证据；预测不是实际测量。

## 必须通过的例子

“用左臂把红色和绿色物体放进蓝色盒子”：红色放置后，右腕能看到绿色而左腕看不到，不是移动补观测的理由。使用或取得放红之后的当前帧，分析绿色及当前环境，按需要由 JEV 更新地图，继续评估左臂抓取。已在帧中取得的几何不重复分析；未出现新的缺口不调用移动观测或 VLM。

若目标被遮住但夹爪反馈明确持有，先区分持有状态与目标身份：使用已绑定的抓取历史身份及反馈进行验证；不强求再次看见目标，不把“夹住东西”单独当作“夹对目标”。
