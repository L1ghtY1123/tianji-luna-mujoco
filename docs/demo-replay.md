# Tianji Luna MuJoCo 实验证据回放

工作台「查看本次实验」或 `/replay.html?run=<id>&view=graph` 打开归档。查看图、RGB、掩码或碰撞模型只读取已有文件，不采集新帧、不调用模型、不执行机器人动作。当前执行契约见 [原生图说明](native-graph-implementation.md) 与 [技能指南](luna-skills-guide.md)。

## 任务图

默认打开 graph。Responses 在线生成完整 graph/subgraph/node/edge，执行前图校验失败可修订最多两次。版本选择器展示初稿、各次修订及绑定永久 ID 后的执行图，校验错误随版本保留。子图可通过当前目标绑定循环处理不同实例，也可以声明独立物体任务；不要求每个永久 ID 都对应一个子图。运行时 Decisions 选择最终图中已有 edge。归档和导出仅供回放审阅，不提供成品 graph 的离线执行入口。

- 顶部按「主图」「任务子图」「失败处理 / 恢复」分组导航。正常路线与失败处理分开显示，所有原始节点和边均保留；跨视图入口和返回边可以点击跳转。共享子图保留其原属 scope，不改写编排。分别计数当前视图节点、已执行节点和实际调用次数。每个框对应一个编排 node，标明 skill、subgraph、router 或 end 类型、节点 ID、最近一次调用序号及结果。subgraph 框进入被调用子图，主图卡片返回。
- 完整拓扑按三列折行分区，每行从左到右。success/yes/no/empty 从入口可达的节点在正常结果路径区，其余分支在独立失败处理视图。相邻正常边用虚线箭头连接，其他边用带目标编号与用途的跳转连接，点击定位目标；不再让不同边共用一束长线。布局不因执行失败删减或重排。初始采用 100% 字号，可缩放、适应宽度和双向拖动画布。
- 未执行节点和未走过的连接保留灰色。所有编排边都有直接箭头或跳转连接，×次数标出实际转移，实际异常转移着色。图内编号只用于定位节点，不是物体 ID 或执行次序；逐次调用及当时物体 ID 在执行记录中查看。详情列出全部关联边、实际次数和每次图调用的次数上限。
- 节点颜色表示最近一次结果：绿为成功，红为本次失败，黄为证据不足／中断，蓝为执行中。failure 表示本次要求没有达成，unknown 表示尚不能确认；二者均可沿 graph 已声明边继续恢复，不等于整个任务终止。任务最终结果独立展示；predicate 的 no 是判断答案，不自动视为执行错误。同节点的历史失败和缺证次数保留，完整调用记录不被后续成功覆盖。
- 实际执行表按开始事件编号，记录时间、结果及实际下一条边。未开始的节点不冒充成功；中断但没有结果的调用不算成功。
- 顶部「实际失败恢复」按真实执行事件列出触发节点、原失败、选择的分支、恢复子图及内部步骤、返回主线的节点和返回后结果。每一步可点击定位到对应子图的具体调用。恢复步骤成功与重试检查点成功分别显示；没有归档边时不推测已进入恢复。
- 旧归档如果在发出节点结果前异常退出，只在 run_end 明确记录了失败及相同 active_policy_node 时，将该实际调用显示为失败并给出原始原因；不补造未走过的 edge。其余没有结果的调用仍显示中断。
- SVG/PNG 导出当前视图及跨视图边界连接和结果图例；JSON 导出完整编排。未执行的初稿和修订版也展示完整拓扑，不借用最终图的执行结果。Responses 次数按第一个实际 graph 节点划分为开局编译与运行中调用。缺失归档不从技能调用倒造 graph，旧格式仅保留原始证据。

## 阶段碰撞场景

每次 build_scene 的归档独立显示，不使用当前地图冒充历史状态。列表显示时间、全局/局部和阶段目标，正文显示当次用途及明确排除的对象。

- CAD、OBB、cuboid 共用每实验稳定的实例颜色。参与环境碰撞的几何显示半透明面和同色轮廓；从环境层排除的对象只有虚线轮廓；桌面使用浅灰蓝。
- 下方图例显示归档物体名称、几何类型和参与/排除状态，默认不显示永久 ID 哈希。颜色只用于显示，不改变碰撞几何或判断。
- 「阶段详情与技术标识」保留 ID、场景版本、观测版本及原始建图参数。名称来自归档清单或该阶段标签，不根据颜色猜身份。
- 全局更新当前观测实体；局部更新指定实体，其他有效层保留。二者都不保证全空间可见。从环境排除抓取目标不表示 attachment 已建立。
- CAD 顶点/面来自当次内容寻址资产；旧实验缺少阶段、范围或排除原因时明确提示未归档，不补造。

## 图像、清单和模型输入

观测按 observation_id 合并为同一次采集，保留原始 RGB、程序身份/几何叠加及实际模型输入三个来源。拍摄时间与标注事件时间分开，后来的持物状态不能证明旧图已经抓取成功。

Responses 初始参考框、SAM3 候选框和程序身份框分别显示。实际发送图片和 questions 从模型请求归档读取，包括 question.instructions 内的图片；不以结果叠加代替模型输入。请求采集 ID 与参考图来源 ID 保持分开，旧记录没有来源字段则显示未记录。

清单只读取明确 task_progress 快照，展示永久实例、实际转移和输入/产物谱系。几何提议不是完整任务清单，历史位置不是当前测量。仅浏览不会触发 SAM3、FoundationPose、OBB 重建或 Decisions。

模型详情保留原始选择和概率。predicate 概率低表示该命题不成立的可能性高，不统一解释为判断失败；有效 no、证据不足 unknown、拒答和传输错误分别归档。verify_place 的定性视觉判断不要求重新建立场景。

## 候选、文件及实验管理

抓取候选按归档采样轮次和阶段展示；颜色区分通过、失败、未知。夹爪坐标轴使用实际归档变换，显示 X 红、Y 绿、Z 蓝。批次通过不等于整个任务完成，缺失的旧候选不补造。3D 支持旋转、缩放和重置视图。

视频、图像和原始文件可预览或下载。视频归档异常不自动改写物理任务结果。实验列表支持筛选、多选和批量删除；删除需确认，运行、编码或受保护的记录由后端拒绝，归档移入回收区而非永久清除。删除当前回放会清空详情。

当前改动的浏览器截图、构建与实际仿真结果见 [2026-11-04 验证报告](replay-policy-clarity-20261104.md)。历史运行证据仍保留在 data/experiments 和各日期的实验报告中，不作为当前执行流程。

共享子图默认显示最近一次调用，可切换前次调用或累计记录。调用范围由父 subgraph 节点真实开始/结束事件确定。保留完整拓扑，只过滤执行证据，避免第一件的成功覆盖第二件尚未执行的步骤。
