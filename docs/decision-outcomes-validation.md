# Decisions 结果与恢复分支验证

2026-11-03。本轮保留一次初始 Responses、显式 version=2 图和 21 个固定技能；没有修改算法服务、CAD、官方 SDK、碰撞检查或 0.8/0.2 事实门槛。

## 修复

- router 原先将 Decisions 结果转换为 bool/None，丢失问题、概率、原因和请求证据。现在传递结构化结果，unknown 沿原有 unknown 边执行，后续节点和回放保留证据。错误的 callback 类型明确拒绝。
- 公共判断解析器接受有类型 refusal，保留 unknown 且不补造概率。放置核验及结果重算不再因此报格式错误或 KeyError；身份配对拒答保留全部原始答案并明确报告 visual_identity_unknown:model_refusal。删除拆包解析器重复实现的拒答分支。
- unknown 来源区分命题概率不确定、事实选择未达门槛、模型明确选择 unknown、模型拒答。操作建议仍不使用事实确认门槛。回放展示实际解析器采用的规则，避免把 CAD 候选提议误画成事实确认失败。
- 放置必要条件采用合取语义：任何明确反例即为 failure，不被另一项 unknown 掩盖；失败条件与缺失证据分别保留。未知不自动授权移动或重拍。
- Responses 的 router 字段及 prompt 明确要求单一判断和正确的 no 语义。恢复资格与当前执行臂分别判断，不能把“不可恢复或不是 A”误当成“当前是 B”。
- 完成要求拆分历史加工、最终交付、执行顺序；来源残留独立判断。删除拼接同一组条件后重复询问的 goal_satisfied，所有独立条件、来源闭合与最终实际姿态仍需通过。公共里程碑说明不再禁止评价条件明确要求的当前事实。

## 原始复现与定向检查

修改前通过直接执行确认四个问题：公共解析器拒绝 refusal；概率 0.65 仅记录模糊的 gate 原因；“目的地明确错误 + 是否仍夹持不确定”被分类为 unknown；router 丢失概率及诊断证据。

修改后检查通过：

- 概率边界 0、0.2、0.2001、0.7999、0.8、1；明确未知选择与低置信度选择分别记录。
- 拒答不补概率；错误名称、缺失概率、布尔概率、NaN 仍作为协议错误拒绝。
- 放置拒答、明确否定与正常成功三种结果；合取否定优先，不影响其他原始答案。
- 用受控 HTTP 返回验证实际 Decisions 请求、解析和归档，低 confidence 操作 proposal 不被事实门槛否决。
- router yes/no/unknown 路由、证据保留、图不变和旧 bool callback 拒绝。
- 最终实际生成的 61 节点图注入受控首次规划失败：A→B、B→A 两种可恢复情况均接回任务，不重播抓取；两种不可恢复情况均停止且不执行抓取。这是控制逻辑探针，未验证真实物理换臂成功率。
