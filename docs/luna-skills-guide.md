# Luna 当前技能与模型边界

本页描述当前实现；历史测试数据留在各实验报告中，不能作为当前 prompt 或技能合同。开发约束见 AGENTS.md，完整技能参数与前提见 skill_catalog 中对应 contract.json 与 SKILL.md。

## 编排

开局优先一次 Responses。模型用显式路由组压缩同目标、同次数的边，模型声明的 `on_failure/on_unknown` 提供作用域公共失败去向，显式路由覆盖默认。程序展开为普通运行图并生成边 ID，随后使用现有完整校验。执行前保留最多两次校验修订。产物核验将同次采集的唯一 RGBD 测量定位参考与实例登记一起提交，后续身份关联接收该参考。

Responses 接收的 `compilation_memory` 保存历史图校验约束、反例及真实终止技能失败证据，并按可执行技能契约指纹选择记录。技能参数、前提、结果及失效规则来自当前注册契约。每轮修订按作用域显式替换、添加或删除，保留省略的定义和先前修订错误，对合成后的完整图检查数据流和恢复覆盖。同一冻结任务最多两次执行前图修订。详见 `docs/responses-compiler-validation-20261107.md`。

时间记忆数据库保存实例集合与历史，空间记忆保存碰撞场景及其版本和有效性，任务账本记录本次执行责任。技能的物理回执经 `ObjectOperation` 更新历史，观测经 `ObjectObservation` 更新实例证据，`GeometryObservation` 进入执行层测量缓存。建图经 `CollisionUpdate` 请求发布空间记忆，规划所需冻结观测及配置区域由执行层保管。执行层向 graph 返回 `GraphSkillResult`，向 Decisions 提交单题 `DecisionQuery`。当前接口及各提交时机见 `docs/native-graph-implementation.md`。

Skill 封装可靠操作，提供稳定的参数、前提、结果和失败码。内部固定调用感知、数值算法及独立的 Decisions 判断，再按照契约汇总结果。跨技能的顺序和恢复路径由 Responses 生成。正常空手身份与支撑 unknown 检查观测恢复覆盖。单一路径直接执行，多方案由 Decisions 选择。数值抓取失败依据拒绝原因采用有界替代路径或结束。恢复内部和重试失败不要求递归恢复。

例如 plan_grasp 在技能内部执行有界候选筛选与规划。应用识别 cuRobo 正式的各阶段失败状态，校验整批候选的失败证据后继续既定采样轮次。整个技能用尽能力后，将明确结果交给 Responses 已生成的恢复分支。

`pool_exhaustion.scope=internal_frozen_candidate_pool` 明确限定当前候选池；`pool_expansion_not_permitted` 只禁止该冻结输入的内部采样扩展。它不否定 graph 中合法的回位、观测、重新生成抓姿等恢复。精简 Responses 输入包含 contract 的观测恢复说明，末尾检查要求核对这一路径；原样重规划不等于观测恢复。

用户未规定顺序时，Responses 在满足任务依赖的可选输入中优先考虑暴露的抓取面、遮挡少、周围间隙充足和通路畅通。初始 RGB 提供这一估计，实际运动可行性随后由技能验证。物体数量由当前清单和任务决定。

Decisions 的调用范围包括跨相机对应、跨时刻永久身份、新实例登记、恢复所需可见性、CAD 选择、当前支撑关系、双臂均可用时的选臂、地图范围选择、放置语言和 XY 候选选择、放置/拆包核验、任务完成及图中 router 判断。每次请求只处理一个问题，数值碰撞、IK 和轨迹检查由算法完成。verify_grasp 只检查执行与机械反馈，不询问夹持/未夹持，不确认物体清单状态。

自然语言、三相机初始 RGB、工作台配置、CAD 目录和技能说明输入 Responses，生成候选清单及 version=2 graph/subgraph/node/edge。任务技能执行前，图校验错误可以反馈给 Responses，最多修订两次，首次通过即采用。修订保留原清单和根任务，使用相同冻结输入。graph 可循环选择当前输入并调用共享逐物体 subgraph。清单独立记录和更新实例历史。运行时 Decisions 根据当前事实选择最终图中已声明的 edge。

正式注册表包含以下 22 个能力；旧 plan_transport、execute_transport、drop、verify_drop 的契约和执行器均已删除。

观测恢复采用已编排的“回配置观测位姿 → 重新观测 → 补齐失效前提 → 重试检查点”。配置回位不再额外询问是否遮挡；额外腕部视角才要求视觉缺失判断。空手、地图有效性、碰撞和执行反馈检查保留。仍持物时不能进入空手恢复，重新观测也不能直接证明数值不可达问题已解决。observe_scene 会清除旧放置区域和规划，图须在后续抓放前重新建立所需事实。

identify_target 的当前支撑问题优先展示同时标有目标和候选支撑物的视角，保留全部三相机。历史支撑或初始容器提议只用于提出一个待验证的当前关系，不直接变成事实；明确 no 后排除该候选，再独立选择其他支撑，unknown 不重问。模型同时得到候选的当前 CAD/支撑面几何及明确标为历史的桌面/操作记录。恢复次数耗尽的分支保留在回放和状态中，但不再出现在 Decisions 可选操作里。

plan_place 的失败摘要保留已解析候选数量、失败阶段、SDK 原始状态和 resolution_id。批量求解的 completed 文本不是成功标志。持物时只能选图中合法的有限规划重试或其他可执行路线，不能进入空手观测恢复；重试保留目标、碰撞和轨迹检查。

choose_arm 只做选臂计算，标记为 retry_safe，恢复可在当前证据和前提满足后重新选臂。plan_place 不缓存数值失败来阻止 graph 已选择的有限重规划；每次调用仍先校验当前前提并进行完整数值求解。执行动作的防重复保护以及 Decisions 同一冻结输入的缓存保留。

identify_destination 对非声明目的引用提出语义许可问题时，同时提供选中区域与声明工作区/最终目的地的配置、当前测量和放置模式。区域名称不同不代表物理位置不同，名称相同也不代替测量与约束检查。

verify_place 的位置问题优先展示带目的区域投影的当前视角，保留全部相机。视觉核验传入 graph 的结果保留每题原始概率、判断及观测/请求/释放绑定。释放后 unknown 进入已编排的有限观测恢复，多方案时使用 Decisions 选择，重试点只能是核验；不能重做已完成的抓取、转移、释放或加工。缺少当前地图时先补齐移动前提。

move_to_observe/return_to_initial_pose 不再把“目的区域核验成功”当作空手移动的唯一依据。关系 unknown 时要求原释放/开爪及撤离回执，以及包含该目标、采集于释放后的当前 observation 碰撞地图；保留地图不能代替这一条件。移动不把未知关系改成成功。

Decisions 原始答案与程序转换规则分别归档。技能异常携带结构化 status=unknown 时，执行器保留 unknown，明确否定和数值失败进入 failure。事实阈值不变；拒答无概率，不能当成格式错误或填零。verify_place 的必要条件中，任一明确否定优先返回 failure，即使其他条件 unknown；未满足项和缺证据项分别保留。恢复 router 传递结构化判断及原始证据，只沿 Responses 已声明的边执行。

恢复分支的 Decisions state 仅呈现技能结果、失败码、执行阶段、拒绝原因统计和候选池结果。轨迹、点云和批量规划调试数组留在实验日志。已确认身份供当前操作复用，恢复所需可见性独立判断并记录。

## 什么时候用视觉算法

| 需要的结果 | 输入及计算 |
|---|---|
| 可见性、语言关系、定性放置结果 | Decisions + 当前三相机 RGB；通常不需要 SAM3/深度/新几何 |
| 当前实例位置与碰撞几何 | SAM3 掩码、Decisions 身份关联、RGBD/标定 |
| 已知 CAD 当前姿态 | Decisions 选目录模型后，FoundationPose 使用该 CAD、当前掩码和 RGBD；选有效深度最多的相机，再转世界坐标 |
| 未知物体几何 | 当前掩码对应的实测点拟合 OBB，绑定永久 ID |
| 桌面与碰撞场景 | 实测 cuboid + 当前 OBB + 已配准 CAD；不从仿真真值补全 |

实例身份、CAD 选择、支撑关系、可见性分别提问。CAD asset ID 可被多个永久实例 ID 共享。已确认 CAD 对应可以缓存，新观测仍更新姿态；局部更新保留其他实体的历史证据与失效状态。

observe_scene 成功只证明本次采集完成分析，不保证每个待处理输入都有当前几何。缺少当前唯一实例时，identify_target 返回 unknown / observed_instance_missing_or_ambiguous。两个腕部相机会随动作改变方向，机械臂也可能遮挡固定相机；fresh 采集不改变视角。Responses 选择下一目标所需的观测姿态及合法恢复分支；Decisions 诊断视角缺口后才能沿已声明分支补观测，不以身份歧义或低置信度代替遮挡证据。

select_target 读取当前候选、任务要求和已验证历史，成功绑定 $selected。identify_target 建立当前操作对象并绑定 $current。加工成功后 $product 表示独立产物。新一轮选择清除上一轮结果绑定。empty 由 graph 连接独立完成验收，数量任务仍需满足明确数量。

物体清单使用 SQLite 持久化永久数字 ID、观测与操作历史。新增物体可以进入下一轮选择，暂时不可见保留历史，输入被消耗与产物创建作为关联记录保存。/api/objects/{id}/history 提供单实例历史查询。

## 放置与核验

普通目标区域从四分开始，按 4→8→16 子区域逐层提出 XY；Decisions 依据原始语言选择候选 ID，数值算法再求接近碰撞阈值的 Z。工作台“指定/设定区域”直接使用配置 XY。默认保持抓取姿态；工作空间包络、携物/夹爪碰撞、IK、轨迹检查分别执行。中间工作区不能冒充最终目的地。

verify_place 由 graph 显式调用，复用同一冻结采集，每次 Decisions 请求只判断一个事实，分别判断支撑/入容器关系，以及适用时接近目标子区域。接受位置误差，不调用 SAM3、FoundationPose、OBB 或释放后深度测量。动作反馈、释放位置、采集时序及身份绑定仍校验。确认后的地图预测更新不伪称实测。

当前身份记录独立判断和请求来源。已接受对应直接提供该主体的可见事实，按需判断恢复视角。同采集身份使用三张完整 R/C 标注图，跨采集只增加相关参考。放置核验和当前语义判断共享三相机视图，questions 使用文字引用。源 RGB、掩码与标定的来源核验在程序侧完成。详见 docs/decisions-questions.md。

verify_place 不因最后一个物体追加全局清单判断。全局完成由 graph 中独立 verify_task_completion 调用完成。all 范围的当前来源残留问题使用独立的当前 RGB 证据，必须明确回答没有匹配输入残留；历史加工和交付使用相应回执，最终位姿记录实际机器人反馈。最终双臂回配置 observation 位姿是保留的要求，由 Responses 显式编排并用关节反馈核验。中途回位、观测、建图没有统一交付后强制流程。

## 失败与证据

plan_grasp 对未知 OBB 的内部候选池预算为 256、512、1000、1000、1000、1000。只有上一池全部得到明确数值拒绝，且场景、目标、机械臂和参数绑定一致，才搜索下一池。CAD/OBB/cuboid 场景的完整双臂碰撞拒绝也是有效证据；不完整证据不能重试。已知 CAD 只使用原离线池。此搜索不生成 graph 节点，也不执行动作。

`planning_no_valid_candidate` 在执行机器人运动前报告当前臂候选均未被接受，details 区分规划、端点、接触和指令碰撞检查。`pool_exhaustion.outcome=not_retryable` 只结束该冻结搜索的内部扩采，不证明其他图内替代不可行。换臂等合法恢复由 Responses 预先声明；Decisions 不生成恢复动作。

看不到、看不完整、遮挡与明确否定分开判断。缺视角证据时由 graph/Decisions 选择合法补充观测位姿；相同输入不自动原位重拍。no/unknown 不重试到 yes，也不降低事实门槛。临时网络/服务失败可有限重发同一冻结请求，但不能重放机器人动作。

恢复可见性检查引用原始失败节点及其实际参数；中间成功的 build_scene 或 router 不能替换该失败。识别失败时，问题直接写入失败参数中的永久 ID 与已登记外观，避免把“失败操作所需主体”误解成另一个物体。诊断缓存同时绑定采集、动作 epoch 和原失败。

运行时恢复不得覆盖数值碰撞失败、修改任务目标或重播已完成物理效果。回放读取真实模型 graph 与事件，不从技能顺序反推编排。旧 steps 归档只保留原始 JSON，不提供兼容解释器。

prepare_unpack 消费当前输入在 VLA 工作区的已验证释放回执，不重新产生回执。identify_target 或 identify_destination 重绑定会清除当前转移确认；仅为刷新几何不必重绑定同一个目标。共享动作子图的防重播键包含输入永久 ID、声明的子图调用路径和动作节点，允许不同输入或不同调用处复用，禁止循环重播同一次物理动作。每次调用仍须满足当前技能前提。

放置候选全部可见且全部明确 no 时是 failure；缺可见/语义证据才保留 unknown。身份、清单闭合和其他视觉问题共用严格返回格式检查；refusal 是无概率的拒答，不是 0 分或协议错误。

碰撞回放以实际 build_scene 快照为准，展示节点、用途、更新范围、保留层与排除目标。同一永久 ID 跨阶段同色；实心表示参与环境碰撞，透视虚线表示该阶段被排除。局部更新不等于最终世界只含局部实体。

补充视角直接询问 `recovery_view_limited`：当前任务所需视觉证据是否因画外、裁切或遮挡而不可得。原有 0.8 门槛不变；具体原因的独立概率只作诊断，不要求某一种原因也越过门槛，不相加概率。明确 no 或 unknown 仍禁止该恢复移动。问题绑定原失败和永久主体 ID，图仍需显式声明补观测节点。

容器抬升参考只使用当前已发布且有效的 CAD/OBB 包络，计入与源容器 XY 包络重叠的有效障碍；保留层不要求重新分割。已消耗输入通过 retired_entity_ids 标识，不再按 initial_parent_id 找历史邻居或读取旧 completed_target_ids。场景版本、容器高度、持物包络及轨迹碰撞检查保持。

已授权整区的 verify_place 按问题裁剪输入。支撑/区域判断只包含目标外观和目的地，夹爪反馈只保留在执行层，不发送视觉夹持问题。Responses 还需考虑释放后核验缺证据的恢复，合法换视角后只重核验原始释放，保留原动作回执。

恢复由 Responses 在线编排为有限 subgraph，内部调用普通 skills，并显式回到失败检查点。Decisions 分开判断失败事实和分支选择。Registry 为两者提供同一 outcome_contract、参数、前提、输出及错误。所有相机共同参与融合，缺失相机贡献零点并留档。

放置使用当前物体绑定的实测目标区域及其版本。resolve_placement 在区域中寻找落点，控制台指定 XY 时使用该坐标。清单数量和物体编号不参与区域划分。每个物体的转移分别保存区域几何，后续放置不覆盖已确认转移的证据。

放置候选数值耗尽时，Graph 和后续 Decisions 接收 `details.placement_search`：尝试次数、候选拒绝原因统计、搜索上限与结论范围。失败仅限当前抓姿、场景及已采样 XY，不等于整个目的地都不可行。该摘要不经过界面列表压缩，重复投影不丢失统计；恢复仍由已编排分支处理。

build_scene 初次必须成功发布 global 基础场景，才能使用 local 更新。该前提由空间记忆持有，通过 collision_map_initialized 暴露给技能契约和编译检查；几何失效不会清除基础场景已建立的事实，新任务或重置则清除。显式 local 省略 entity_ids 时使用当前 target_id，包含选中的产物。显式列表按指定物体刷新，global 更新当前观测的清单实体。scope=decide 在没有基础场景时只有 global 合法，无须模型判断；已有基础场景时由 Decisions 选择范围。显式 local 不会被偷偷改成 global。

已交付物体与其他有效清单实例使用同一身份关联入口。当前多视角候选、历史参考图、产物参考和操作历史共同提供身份证据。接受关联后用当前掩码和深度更新几何，保留关联不确定的明确反馈。交付完成事实继续使用既有核验回执。

身份请求保留当前观测编号和已核验释放的历史位置，并明确记录释放核验是否使用当前同一次冻结采集。尚未核验的释放记录保持待确认。产物参考图保留观测编号和历史图像含义。

同次采集内，已接受的身份回答及已确认跨相机对应的候选标签传给后续单题请求，图像保留这些主体的标注。低置信度回答继续待确认。机器人部件和背景属于清单外候选。

当前待判断候选同时提供原始 RGB 矩形裁剪，标为 current_subject_detail，完整视图和历史参考继续提供上下文。

目标区域的 RGB 核验投影使用原图分辨率，标签贴边绘制，保持区域内部清晰。

身份选项保留 Responses 为每个实例生成的完整参考说明，并明确标记为历史描述，包含相机和同类实例间的位置区别。

机器人外观使用灰白色，腕部相机使用中性灰色。Responses 清单及 Decisions 实例关联的主体范围为外部物体、容器和支撑面，排除机器人本体、关节、夹爪及随机器人安装的相机和线缆。

身份关联前，使用已有 URDF 自身表面射线匹配、采集时的关节与夹爪反馈、三相机标定 RGBD 过滤机器人返回点。物体与容器候选都参与。保留真实接触歧义和原始 RGBD，过滤只确定机器人表面归属。

当前观测已提出支撑物时，Decisions 用一次 predicate 核验该直接支撑或容纳关系。提议仍需独立接受，明确 no 返回 failure／observed_support_rejected，证据不确定返回 unknown／observed_support_unknown。缺少当前提议时用一次 choice 在已登记支撑物中选择，保留 none_of_listed 与 unknown；明确 none_of_listed 同样是拒绝。同一采集复用已接受结果，原始 probability 或 confidence 分别归档。支撑历史只读取物体记忆，不读取任务完成状态或尝试次数。机器人自身过滤在身份关联前执行一次，过滤证据沿用到几何输出，原始轮廓用于后续边缘处理。

observe_scene 保留当前身份提议与带日期的已确认参考。每题只核验一个当前候选与永久实例的对应关系。拒绝或不确定保留未关联状态。早期产物全景照片在取得已确认实例参考后退出当前身份请求。

容器跟踪按已确认实例保存参考，其他物体不可见或新增清单记录不会阻止已有容器的测量对应。容器自身身份变化、深度变化或标定不兼容仍使对应失效。

CAD 的 FoundationPose 位姿跟踪由独立物理记忆上下文启用：执行层传递运输／加工历史和几何失效状态，不传 graph 的 visual_progress。上下文未变时，旧位姿只初始化当前 RGBD 的 track_one；上下文变化时重新配准。姿态来源、坐标绑定及放置能力检查保持不变。

执行技能的 TimeoutError 统一转换为 failure 及原始错误证据供 graph 处理，包括夹爪稳定超时；部分执行状态和禁止普通重放的保护继续保留，不能用延长时限或放宽稳定阈值冒充成功。

视觉缺证据的有限恢复覆盖目标、目的地绑定及释放后核验。Responses 显式编排建图、移动、分析和重试检查点。配置回位无需额外视觉缺失谓词；额外腕部视角才独立核验当前视觉缺失。中间建图成功保留原失败，原检查点重试成功后解除活动失败，历史事件保留。

select_target 清除上一件的操作上下文，保留清单历史与有效观测地图。choose_arm 在数值算法前检查目标和目的地当前测量，缺少任一测量返回明确 unknown。

身份请求传递带原始观测编号的历史实测位置，与当前候选的世界坐标共同提供身份关联证据。未见、提议更新和新任务保留原测量时刻，接受新的 RGBD 测量后才更新该记录。

verify_unpack 的产物出现与包装消失分别使用一次 Decisions 请求，每次共享拆包前与当前三相机图像。两项事实可以由不同相机提供证据，明确否定返回 rejected 并沿 failure 边，缺证据返回 unknown。程序继续校验动作回执、采集时序、目标绑定与测量来源。

verify_unpack 内部采集当前三相机 RGBD，并建立加工结果与产物 ID。后续 observe_scene 使用已登记的产物身份获取掩码与几何。

编译阶段把 TaskSpec 要求的最终位姿纳入完成核验前提及图成功出口校验。抓取、放置和加工动作清除旧观测位姿事实，运行时继续使用实际关节反馈验收。

身份关联的代表视图优先采用当前 Responses 提议中与 SAM3 候选框对应的相机。各相机分别关联永久实例，按已接受的相同 ID 融合深度。过期提议不参与当前视图优先级。

身份请求始终保留当前三相机 RGB，包括没有所选 SAM 候选的相机。当前可见表面范围与历史实测位置分别标记。同次采集的已确认产物记录保留创建证据，重复参考图退出请求。近似候选框与外观查询只用于安排比较次序，每个 ID 对应关系仍由 Decisions 独立核验。当前关联 unknown 附在对应候选的 unassociated_candidates 中，已确认实例继续处理。new_instance 获得确认后独立登记永久 ID。

碰撞依赖来自当前测量、保留图层、动作失效的物体以及当前目标和目的地。单纯的未见历史清单条目不新增必需图层。当前操作或受影响物体缺少有效几何时，继续返回明确失败。

存在已确认可选输入时可以继续选择。没有可选输入且仍有未关联候选或 unknown 新物体提议时返回 unknown，并保留对应证据。已拒绝提议不阻止 empty。

产物 current_region 使用产物自己的已确认支撑或明确位置，输入物体的加工区域不传给产物。

恢复 router 声明 choices 并对应已有 edge.on。Decisions 每次选择一个声明分支，使用原始失败、待确认候选和剩余次数。可恢复失败到达此选择器，缺少合法恢复的失败直接明确结束。成功技能沿 success 边直接继续。

时间记忆更新只读取当前操作回执：物理释放使旧位置失效，绑定一致的 Decisions 放置核验确认新位置并记录转移。任务账本不再覆盖清单物理字段；新观测中的旧清单副本也不能覆盖当前操作历史。恢复对同一检查点和选中输入最多一次，恢复中失败/unknown 或重返检查点后再次失败均显式结束，不恢复失败的恢复。

身份细节图使用保留周围区域的原始 RGB，不将轮廓叠加到紧裁剪里；当前全景继续提供 SAM3 掩码、候选标签及三相机视图，深度与历史状态不变。避免小目标的外观和接触/分离关系被裁剪、描边遮蔽。

固定/精确 XY 的抓取前放置端点筛选与正式放置共用冻结实测表面质心作为物体位置参考；只筛选该指定 XY，不以区域内另一位置作为通过证据。普通区域继续原有有限分区。该筛选只检查固定夹爪端点，不宣称全臂 IK、持物或完整轨迹已通过。

拆包视觉核验比较整个实测桌面的前后变化，产物不必与原包装同位置。产物新出现与包装消失仍分别请求 Decisions；返回原因列出缺失或否定的具体条件，阈值和动作/身份绑定不变。

identify_destination 已确认的中间转移许可，在目标、目的地引用、任务、采集和区域配置完全一致时由 perceive_placement_zone 复用；不再当作最终目的地重复核验。区域内部语言限制仍独立判断，变化或未确认的许可不复用。

跨视角身份输入补充同次采集的实测表面投影：将已确认实例的三维点投影到待判断相机，与当前 SAM3 掩码及深度比较。Decisions 仍独立判断身份，不增加问题，不用几何匹配代替永久 ID 裁决；部分表面覆盖与完整轮廓 IoU 明确区分。

新产物在首次掩码定位前，保留并传递实际创建核验命题、原始答案、单题请求哈希及对应加工前/后 RGB。引用按实例、输入对象、观测、代次和图像哈希绑定。Decisions 仍独立判断当前候选是否对应该产物；创建成功不自动接受候选身份。已有带位置参考的身份被确认后，不再重复发送创建对照图。

时间记忆按事实逐项更新：已确认位置和支撑不因子区域核验 unknown 而丢失；旧支撑在物理释放后失效。身份请求明确区分初始同采集提议、已确认同采集实例、历史实例与产物首次定位。未见只更新 visibility；ObjectRetirement 需要明确来源、观测和回执，移除/消耗保留历史及 ID。removed 与 consumed 均退出当前身份候选，保留退出原因与历史；不自动恢复退役 ID。暂时未见的活动实例仍可正常跨观测关联。空间记忆用退役 ID 更新活动几何集合，不以未见直接删除碰撞对象。

VLA 效果定义统一来自 resources/vla_unpack.json 的 effect：粉色包装输入、独立黑色产物、视觉确认后消耗输入。动作回执不代替视觉事实。ObjectMemory 的退役接口供明确的执行回执/操作者确认使用；本次不增加“看不见即删除”的自动判断或隐藏 graph 节点。

产物创建保留输入所属场景归属。持久化以当前 ObjectMemory 为提交主体，数据库查询结果不反过来筛掉尚待写回的事实；原始场景归属不能被普通状态更新清空。

当前身份关联只处理活动清单。确认退出的实例保留历史，不再自动参与重识别；后来无法关联活动实例的物体，经过独立新增确认后登记新 ID。未见不等于确认退出，也不因此分配新 ID。

execute_grasp 在抬升前使旧当前位置失去保证，夹爪反馈单独记录。抬升后的 verify_grasp 只检查执行层机械反馈，不询问视觉夹持，不向清单写入 held。execute_place 在开位确认后、撤离前记录开爪事件，不能据此改写视觉支撑/位置。Controller 先持久化再更新实例快照。verify_place 通过视觉补充当前支撑及区域结论。verify_unpack 的输入退役、产物登记和双方历史以一个 SQLite 事务提交；共享 VLA 效果进入产物身份参考，但实际结果仍须视觉确认。

observe_scene 的历史身份参考包含实测 RGBD、标定和已接受掩码，按永久实例投影到当前视图。投影掩码重叠用于排序，深度差和日期进入单题 Decisions；移动后低重叠只说明旧位置不对应，不能单独否定身份。新观测确认后才替换参考，不能先用待判断候选覆盖旧参考。

夹爪命令稳定等待使用完整窗口内的位置极差和时间加权速度均方根，保留原位置/速度阈值、窗口与超时。记录窗口统计及瞬时最大速度，接触微振不再反复重置瞬时低速计时；持续运动仍返回失败。该检查仅属于执行层，不推断物体记忆状态。

Responses 只编排已注册技能并填写其任务参数，不能修改技能实现、抓姿补偿或数值规划设置。generate_grasps 不接受模型调参字段；未知 OBB 的 GraspGen 抓姿沿执行臂末端局部 +Z 增加 10mm，在 IK 前只应用一次。两臂保持各自安装朝向，CAD 离线抓姿不应用该补偿。


空抓恢复：execute_grasp 的失败回执明确设置 recovery_needed。Decisions 只能选择 graph 中声明的有限恢复分支。recover_failed_grasp 核对当前稳定、全闭合机械反馈和失败动作绑定；成功只清除临时执行模型及旧规划、失效目标几何，不移动、不推断物体位置。随后由 graph 显式观测、建立 observation 碰撞场景、回配置观测位姿、重新观测和规划，用独立 execute_grasp 节点重试一次。恢复或第二次抓取失败即结束；不确定反馈、限位闭合指令和已建立 attachment 均不允许此恢复。

编译恢复覆盖检查：正常主线中，契约可能返回身份/支撑 unknown 的空手检查点，必须提供能够经配置观测回位后重新观测的显式路线。唯一恢复出口直接路由，多方案选择使用 Decisions。路线可由调用方子图负责；恢复专用检查点不要求再次恢复。检查器不插入节点、不改图、不推断物体状态；仍独立检查技能前提与边界次数。


### 放置模式与恢复输入（2026-11-06）

Responses 在 identify_destination 显式选择 `release_mode`：`surface_setdown` 轻放到支撑面；`container_release` 在任务允许投放时于容器上方释放。模式从抓取筛查贯穿落点、规划、执行和核验。盒上释放用既有携物 plan_pose，不新增 skill；完整物体最低点名义高于已发布盒沿 10 mm，可在控制台调整，实际反馈受既有 IK 位置容差约束。底面与盒沿分别保存。完整物体投影须在有效盒口内，保留持物、夹爪、全机碰撞检查；无解不自动改模式或抬高。释放使空间几何失效，下一次规划前必须按 graph 更新。

恢复选择输入同时包含 inline 成功续接路径、各结果边及子图定义，显示分支入口剩余次数；Decisions 只选已声明分支。初始 prompt 保存已验证的通用编排经验，区分规划失败与部分执行后的不同前提，不保存固定任务图。
## 观测后的抓取前提（2026-11-07）

永久物体 ID 与当前抓取依据分开。`identify_target` 提供 `source_support_current`；`observe_scene` 更新采集后使该前提失效；`plan_grasp` 要求它成立。在线 Responses 应在恢复后的再次抓取前显式重新绑定目标，并按已有契约恢复目的地、选臂、场景和候选等依赖。相同采集已有有效支撑证明时不增加 Decisions 请求。该变更只纠正证据时效，不修改规划算法、技能运动步骤、阈值或恢复次数。

观测结果由执行层在数据库提交后更新两个记忆版本；几何变化意味着场景待发布，观测本身不能替代 `build_scene`。未见不删除实例，只有明确消耗或移除证据才退役。


## 抓取与执行边界核对（2026-11-07）

三段式抓取调用锁定 cuRobo 的公开 plan_grasp。执行臂两侧 Link3 夹指和 Link4 连杆在官方 goalset/grasp/lift 求解阶段临时排除，approach 阶段恢复；项目适配器在返回和异常路径恢复链接。逐段命令检查继续核验环境、另一臂、非接触部件和目标接触条件。第三段实际抬升成功、机械反馈通过后，把该实例的 OBB/CAD 转换为 TCP 坐标携物几何并建立 attachment。attachment 回执核对物体、执行臂、任务、采集和场景。

抓取与放置计划携带 MotionPlanBinding，执行前检查目标、目的地、执行臂、generation、observation_id、scene_token 和参数哈希。抓取搜索使用冻结的观测与场景副本。Graph 与 Decisions 收到逐轮候选失败阶段及接触/碰撞摘要。观测恢复允许配置回位或满足前提的腕部换视角；当前已在配置位姿时，分支选择须结合实际证据变化。

首次新实例提议也经过单题 Decisions 确认；unknown/reject 保留提议反馈。世界命名空间由仿真场景实例持有，同一场景的控制器重建继续使用其标识。

初始登记通过感知层共享 SAM3 缓存获得主体掩码和注册深度，向 Decisions 提供当前表面摘要、参考表面投影重叠和深度残差。数据绑定当前采集与代次。登记后的掩码参考进入首个 observe_scene，完整观测通过原有记忆事务持久化。

抓取第二段及闭合的接触许可限定为当前目标与执行臂两侧 Link3、Link4 的配对，共 34 个配置球。这些链接与其他环境物体、另一臂、其余部件与目标及自碰撞继续使用原数值检查。

## 动态批处理与 Decisions 边界（2026-11-08）

all/count 任务采用共享处理子图。每件交付后显式回配置观测位姿，再调用 fresh observe_scene 和 select_target。初始 target_refs 保存初始候选，新观测登记的匹配实例可以进入同一循环。all 以当前来源盒确认清空结束本批，count 按请求数量验收。循环预算独立于初始数量，预算耗尽返回失败。

Decisions 负责实例身份、CAD 选择、任务成员关系、语义位置、来源为空的视觉判断，以及多种合法恢复方案之间的选择。单个候选、已绑定参数、数值规划结果、反馈和版本检查、唯一恢复出口直接由程序处理。普通盒上释放按用户指定规则登记入盒，无需再询问落地关系。工作区轻放和额外落地要求继续视觉核验。

时间记忆记录 container_entry、永久 ID、加工谱系和历史测量。回执来源为 operator_container_release_rule。空间记忆发布对应已测容器的整体包围范围，geometry_source 为 container_occupancy，object_pose_measured 为 false。新单件测量替换该范围。容器几何失效会使依赖它的占据失效。所有后续轨迹仍检查当前碰撞世界。

完全相同的路由声明按 source、outcome、target、max_traversals 合并，次数保持原声明值。不同目标或不同次数仍返回冲突。verify_place 显式声明释放模式，工作区轻放的地图失效前提继续传递，普通盒上释放采用独立的条件性占据发布结果。

每轮实例关联使用执行层投影的 association_scope。当前输入及其产物优先，已交付实例保留物理历史并按需比较。单个身份谓词的历史证据限定到被比较实例，当前已接受主体继续保留标注与几何，帮助区分相似物体。新实例登记前仍检查全部可用历史身份。已交付内容物只有在入盒回执、有效空间占据和当前容器 RGBD 对应一致，且通过已有容器位置稳定性检查，且候选完整有效表面位于占据范围内时，才记录为 deferred_candidates。记录包含采集、场景版本、容器、回执、测量范围和占据范围，identity_assigned=false。来源盒、工作区及未完成物体的已知支撑容器继续完整关联。占据失效、容器对应缺失、候选伸出范围或后续任务重新操作该容器时，恢复通常关联。空间记忆继续保留交付实例的占据；单件位姿保持未测量。association_scope 参与观测复用键。

切换本轮输入时，执行上下文保留与已发布空间记忆绑定的 scene_observation。建图范围判断按可选历史观测处理缺失值。新目标的操作计划及放置绑定继续重新建立。

后续拆包核验读取已交付黑件的当前单件测量，或与入盒回执绑定的有效容器占据。容器占据保留 scene_token、container_id、entry_receipt_id 和 object_pose_measured=false。新产物定位对完全位于该范围内的表面记录 excluded_container_occupancies，单件身份保持未分配；部分重叠继续返回不确定。容器或回执失效时要求重新取得几何。退役实例的历史退出活动产物排除集合。
