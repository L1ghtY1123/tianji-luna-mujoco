# 层间依赖与 Decisions 输入核对

本轮按实际生产者、最终 HTTP 载荷和结果消费者核对，保持在线 graph、单题请求及 0.8 事实阈值。输入边界不是图模板，不限定任务流程。`agent/decision_state.py` 定义通用判断的字段范围；`core/decisions.py` 校验问题结构；图像、采集来源和动作时序仍由各技能检查。

## 层间核对

| 层 | 状态与接口 | 核对及处理 |
|---|---|---|
| Graph | `TaskSpec`、`Graph`、`GraphSkillResult` | 核心类型不导入记忆、模型客户端或机器人。执行器通过回调获取技能结果和判断，不写实例清单。 |
| 时间记忆 | `ObjectRecord`、`ObjectObservation`、`ObjectOperation` | 独立持有物理身份、历史与谱系。支撑历史改为直接读取物体记忆，移除任务尝试次数及任务账本位置。 |
| 空间记忆 | `GeometryMeasurement`、`CollisionUpdate`、已发布场景 | 独立保存测量、失效集合和场景绑定。几何入口不再接收整条任务记录，只读取执行适配器提供的物理记忆与冻结测量。 |
| Decisions | `DecisionQuery`、`WireDecisionQuestion` | 输出判断及声明选项，不改图、不写记忆。每题有明确用途和证据范围；所有生产者在发送前校验单题结构。 |
| 执行 | 任务账本、技能调度、类型适配 | 在边界组合数据、应用判断并提交记忆更新。恢复请求带出实际声明的子图内容及相关技能契约，不创造分支。 |

已删除无调用方的 `visual_assistance.py`、`visual_scene.py`、对应环境开关、预算和状态字段。历史实验文件不属于运行入口，继续保留。存储对旧记录的字段投影用于读取已有历史，不重新启用旧任务流程。

感知内旧 `progress_*` 入口也经单题传输校验；当前 observe_scene 不传任务进度，正常路径的转移核验由 verify_place 承担。该保留接口不是新的观测前提。

## 表达规则

state 提供问题需要的材料，question 说明此次判断。字段名明确区分当前测量、历史记录、候选提议、用户要求和程序回执。日期、相机、永久实例、当前候选及区域 ID 各自保持原意。题目引用的图像／掩码必须确实存在；参考图不得描述为当前图。

predicate 的 probability 是命题为真的概率：0.01 是明确否定，0.5 附近才是不确定。choice 的 confidence 是选项判断的置信度；操作提议与事实认证继续分开。不改阈值、不将否定重试到肯定、不用其他题的期望结果暗示当前答案。

本项目调用 OpenAI `/v1/decisions`，沿用现有协议、模型和单题 HTTP 约定。state 提供当前题目证据，question 只说明本次命题或选择；不使用 TypeSafe 或 Jev。
