# 深度关联与统一放置验收（2026-11-15）

当前证据版本：`depth-unified-placement-v10`。全部模型继续使用 `gpt-6-luna`。

## 当前实现

- 跨相机关联仍由 Decisions 比较带标签 RGB。程序复用三相机同次 RGBD、SAM3 掩码与各自标定，提供机器人固定坐标系中的可见表面中心、范围、有效深度比例和候选间空间关系；不增加深度图片，不做轮廓跨相机投影。
- 明显分离的同次候选不能合并；归组同时检查同相机唯一性和传递一致性。原始模型回答与程序拒绝依据分别归档。候选召回沿用原 SAM3 检索词及别名，其他类别保留为图像上下文。
- 跨时刻输入包含带日期的参考深度、当时相机标定与执行回执。不同采集的位置只作为先验，搬运后的物体不受旧位置硬筛选；完全相同观测 ID 和代次中的已确认身份仍受空间矛盾检查。
- `verify_grasp` 保持实测关节优先：全开未持物，中间位置持物，仅全闭时看当前 RGB；持物后的目标身份按连续执行绑定继承。
- 桌面与入盒 `verify_place` 使用同一判断流程：既有持物记录、实际到达配置释放 XYZ（5 mm 容差）、释放及当前空爪，再由 Decisions 选择直接成功、推测成功、失败或未知。两者均使用 RGB，没有新增深度判断。控制台小方框只约束机器人实际释放位置，不再投影为物体最终落点的视觉验收边界。
- 直接成功表示当前能看到物体放在指定支撑或进入指定盒子；推测成功由上述实际执行证据支持，并且没有可见失败反证。不要求在盒内同形工件间辨认新放入的那一件。
- 直接确认和推测入盒统一保留永久 ID、目的容器及交付历史。已完成交付的内容物退出逐件关联和 CAD 配准；全工作空间重新建图时，当前可见内容物进入匿名 TSDF，盒子本体保留 CAD，桌面保留实测 cuboid。入盒历史不冒充当前测得的个体位姿或几何覆盖。
