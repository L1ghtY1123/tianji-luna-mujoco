# 放置位置：GaP 思路与占用感知实现

本项目保留 GaP 对普通容器和支撑表面的区分，并复用已有采样、实测几何和 cuRobo 检查。运行时只用 Decisions 与 skills；初始 Responses 负责原始任务、物体清单与 graph，不在执行中生成落点。

## 两类几何，一条放置链路

| 目的地 | 实测区域与释放条件 |
|---|---|
| 普通盒子、篮子等容器 | 已观测内部区域、边沿高度和持物尺寸；检查整个占地范围，求容器内释放位姿与竖直进出高度。 |
| 桌面、托盘或其他物体的水平顶面 | 已观测支撑范围与高度；检查整个占地、支撑覆盖和其他物体占用。 |

两类均使用 `perceive_placement_zone → resolve_placement → plan_place → execute_place → verify_place`。这是能力依赖关系，节点及必要观测/建图由 graph 显式安排，runtime 不插步骤。保持抓取时完整旋转；plan_place 仍表示 approach/place/retreat 三段轨迹规划，开爪发生在 place 与 retreat 之间。

## 语言与位置如何分工

`perceive_placement_zone` 复用身份确认后的 SAM3/RGBD 区域，绑定永久目标/目的地 ID。on/inside 表示所绑定几何的物理类型，不能冒充完整语言解释。一次 Decisions 判断检查：原始指令是否允许在这个区域内任意数值可行的位置放置？

- 普通“放到桌上”“放进这个盒子”：只有 Decisions 明确许可整个区域后，数值模块才可以自行选空位。无需逐项询问方向、半区、视角和排序偏好。
- “杯子左侧”“桌面中央”“左侧隔间”：没有整区许可时，对实际位姿候选做语言判断。代码将整个持物占地投影到当前标定图像，保留原始 RGB 并附上编号轮廓；一次 Decisions 请求逐候选判断是否满足原句。只保留肯定回答的 ID。

Decisions 不填写 XYZ。原始任务、当前物体独立要求、永久身份描述、当前测量和候选图提供判断依据；位置与姿态始终由几何计算得到。全为 no/unknown、参考物遮挡、视角歧义或没有可用投影时返回 unknown，不改用整个容器或任意桌面空位。

没有实体边界的“杯子左侧区域”不必先被 SAM 分割成一个物体：桌面提供实测候选，杯子提供语言参考，Decisions 选择符合要求的候选。具名隔间只有在现有观测提供了可用支撑候选、图像能够辨认其归属时才可能确认；没有可见几何时不会补出未知盒底。当前没有另建 DINO 服务或声称实现任意语言区域分割器。

候选判断必须使用与区域几何同一次采集、且动作 epoch 有效的 RGB。抓取后图像过期时由 graph 安排重新采集/关联、区域更新和建图；resolve_placement 不隐藏这些动作。整区许可可以在抓取前取得，此后仍须校验地图和数值位姿。

区域绑定保存这次采集的相机标定及水平左/前方向，也提供机器人基座方向。Decisions 根据原话确定应采用的视角；缺失或退化的方向保持 unknown。释放后使用当前参考物点云在同一组冻结方向上的范围，避免腕部相机转动改写“左侧”。不沿用参考物的旧位置。

## 空位怎样计算

1. 使用持物 OBB 的完整旋转与工具偏移计算占地，在已有支撑采样中选择最多 96 个空间分散 XY。
2. 夹爪和持物球底部决定解析最低 Z；先查离线 TCP 工作空间的有界高度样本。
3. 直接查询当前已发布 TSDF/ESDF 中夹爪球与持物球的碰撞，包含保留的清单层。XY 障碍包络不再作为排除条件。
4. 固定 XY/旋转，批量检查 21 个 1mm 高度样本（至最低值上方 20mm），选首个满足净距的 Z，再核验该 TCP 位置工作空间。物体离支撑面上限默认 50mm，可通过 place_max_release_gap_m 配置；不把悬空避障当放置。
5. 从数值候选中保留最多 12 个分散点，整区许可或 Decisions 对候选的原句判断通过后，才交 plan_place 规划。

这是有界搜索，不保证穷尽所有位置；没有候选不等于整个目的地无解。OBB 几何、采样、attachment、阈值和官方接口依据见 [OBB 与场景查询说明](obb-geometry-and-placement.md)。

## 连续把盒内物体放到桌面

第一次选位使用桌面当前占用。释放后按原任务要求核验实际物体位置；通过显式观测和地图更新获得新占用。第二次选位会把第一件物体纳入障碍，第三次继续使用包含前两件的地图。

已完成物体保留永久 ID 和地图层；暂时遮挡不等于退役。动作会使旧位置失效，只有实测更新才能替换；不能把命令落点写成已测障碍，也不维护第二套假想预约格子。原有“每件物体交付后双臂回配置观测位姿并观测”的用户要求保持，最后一件也包含在内。

## 证据与完成

求解结果绑定原始任务、语义许可、候选、目标/目的地/臂、场景与占用摘要、持物几何/附件设置、观测和规划设置。任一相关输入变化，旧结果不得继续用于规划。

执行绑定保留原始自然语言。释放后数值测量检查物体在当前支撑/容器区域内，Decisions 再根据当前图像核验原句中的相对位置、具名区域、容器关系和已脱离夹爪。数值“区域内”不等于语言条件全部成立，候选许可也不证明物体实际落在那里。

绑定同时保存本次目的地、原始最终目的地与声明的中间工作区。中转验收遵守当前适用的搬运和位置要求，不提前要求完成后续加工或最终入盒；最终任务完成仍由原有任务清单单独判定。目的地不同本身不构成放宽要求的许可。

生产已移除逐项语言解释器 `interpret_placement`。旧有限关系几何辅助函数只供已有直接数值调用与隔离测试，不再作为运行时语言入口。没有运行时 Responses、隐藏物理重试、任意扩大区域或取消碰撞检查。
