## 分层接口说明

- 初始 Responses 输入自然语言、三相机 RGB、公开配置和工作空间能力、实体/资产知识、完整技能契约及图 schema；输出 `TaskSpec`、`task_inventory`、`policy_graph`。它选择顺序、技能、分支、循环、中间支撑及完成条件。
- Runtime 只解析图与绑定 ID、事实、版本和预算。没有固定拆包节点表；非法前提会报告，不自动补回位、建图、重观测或换臂。
- Decisions 承担身份、语义、图条件和动态建图策略；数值工作空间、碰撞和覆盖仍由算法验证。正常目标为一次 Responses，未处理的安全失败须先有 Decisions 明确的新计划判断，才可在共享预算内修订。执行副作用未确认时禁止普通重放。
- 项目开发 skill：`.agents/skills/luna-policy-isolation/SKILL.md`。它约束 Codex 修改代码，不是机器人技能，也不决定运行时任务序列。

## 全局、局部与部分观测

`build_scene` 参数支持 `scope=global|local|decide`。Responses 显式选择时直接采用；`decide` 时 Decisions 根据任务、当前/历史观测、实体变化及地图证据选择范围与局部 ID。没有模型结果不能默认全局。

全局更新当前观测清单；局部只刷新所选实测实体。未再次观测的历史层保留原时间戳和失效状态，已消耗实体明确退役；任何模式都不能把盲区变为空闲。mapper 实际输入的掩码和先验随局部选择过滤，但原始三相机覆盖证据不裁剪。身份不明确与未观测必须区分；历史身份不证明当前几何有效。

## VLA 配置与测量

网页常用参数中的 `vla_unpack.input_x_m/input_y_m` 是物体参考点的世界 XY；独立配置区域 `vla-unpack-input` 为精确落点，普通 `demo-destination` 和实测桌面仍允许自由落点。仅模型选择专用区域时应用该约束。已有抓取姿态和 VLA 双臂准备关节标定保持，前序放置不固定用左臂。

物体参考点采用持物记录中的实测可见表面质心；高度先验补全不改变它。它不是夹爪前端，也不声称是不可见体积的几何中心。释放反馈检查实际物体参考点与配置 XY 的误差。需要物体 CAD 原点作为坐标定义时，须另有实测配准，不能使用仿真真值代替。

MuJoCo 效果内部采样桌面与 B 工作空间内、无碰撞的产物位置；回执去掉物理 ID、前后 pose 和输出位置。处理核验搜索实测整桌，不继续只看输入小区域。黑色点云分离为候选，已有黑实体须有测量对应；多候选或无法排除已有产物时明确失败，不把它们合并成一个新产物。产物独立 ID 与工序关联仍由当前视觉证据建立。
