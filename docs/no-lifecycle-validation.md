本次任务删除旧生命周期执行器和固定两段搬运账本。Responses 提出任务、永久实体清单和策略图；运行时执行图中的显式节点、分支和有界循环。Decisions 判断身份、语义关系与视觉结果；skills 执行各自声明的能力。中间转移不等于任务完成，处理产物使用独立 ID 并保存输入输出关联。
