## 修正

- Luna 仅保留 `web/index.html`。任务、仿真场景、碰撞球、工作空间、回放和 Base 控制台都在当前工作台切换；移除四个旧 HTML、后端独立路由和旧机器人渲染实现。图片放大与全宽 graph 使用当前页。切换保留任务和场景草稿，暂停隐藏的 Luna 诊断视图刷新、孪生动画和视频。
- 碰撞球原查看器主动传入空网格，导致“显示场景网格”开关无效。现在通过 RobotGateway 的显示接口调用 Base 现有无状态 `scene/evaluate`，使用与 cuRobo 球完全相同的实测关节和张开夹爪。Base renderer 一次应用机器人与球；45 个本体网格、38 个 link、383 个球。本体/球开关独立，球默认 35% 不透明度。工作空间同样显示 Base 实测机器人。
- 真机 `observe` 原本只存在 guangyu 的持久用户预设，隔离仿真状态目录没有该记录。Base 现已内置并默认选择它，A/B 精确值来自用户预设，未用左右镜像近似替代。Simulation 在创建运行数据后、第一帧反馈前设置同一 observe 并保持。模型零位不变，物理场景重新编译保留当前关节。Luna 的观测目标也对齐；之前的标定证据单独归档。
- 真机 Base 启动镜像为 `jodell-console:0.2.0`。启动网页不发送回位指令；预设仍经原有计划/执行入口。

## 实测

证据目录：`data/acceptance/workbench-observe/`。

- Simulation 启动保持、场景运行/重编译、PD 跟踪和停止检查：18 项测试及 4 个子测试通过。第一帧是 observe；稳定后最大关节误差 A 0.0493°、B 0.0490°。
- cuRoboV2-Fast：精确 observe 在双爪开、双爪闭、两种单爪闭合配置下，关节限值和自碰撞代价均为零。383 球配置未变，485 个 SDK 文件校验通过。环境安全仍由实测 RGBD 和完整运动规划判断。
- 显示一致性：38 个 link 的 Base 显示矩阵与 cuRobo FK 最大逐元素误差 `3.57e-7`。显示数据不包含手工环境真值。
- RGBD：三路 640×480，同一 sequence，时间偏差 0 ms；7 个不同帧稳定 0.804 s。深度有效，官方 RobotSegmenter 剔除机器人；两个 1280×720 录像帧成功渲染。
- 浏览器：六面板、单标签页、同一 document，任务输入和未提交场景草稿保留；前进/后退、回放深链接、graph SVG、Decisions 图片、视频离页暂停通过；隐藏碰撞球不继续请求，Base 固定位姿默认 observe。没有 JS 页面异常。

本轮没有运行完整自然语言抓放任务。测试读取的一条历史归档录像已中断；视频交互使用另一条确实含 MP4 的归档验证，历史内容未修改。原有球拟合精度与工作空间限制继续以 [模型审核](luna-scene-ownership-audit.md) 为准。
