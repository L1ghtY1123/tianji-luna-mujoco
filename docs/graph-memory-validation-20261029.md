## 具体问题与修正

- 清单没有删除绿色物体的初始来源证明；但 support 判断请求未携带该证明，只依据当前图像重新判断。现在请求包含原始 Decisions 证明、最后观测位置、可见状态、失败尝试计数及已确认转移记录。历史时间戳不变；初始提案、目标要求和未经核验的描述不作为事实。
- identify_target 只绑定状态，不执行物理动作，已声明 recovery_retry_safe；图可把它放在 recover 内，并由 Decisions 选择已有的换位姿节点。缺失当前几何归为 unknown，不能伪造新几何或擅自执行移动。
- 生产入口设置 ResponsesBudget(extra_limit=0)，初始输出 schema 不提供 replan，运行中不追加 Responses。编译器库保留显式预算接口供历史行为测试，网页运行入口不开放额外预算。
- 原静态检查错误地要求所有可选恢复分支在每次进入时都满足前提。修正为边的入口条件决定该边当时是否可用；运行时同样筛选 Decisions 的可选项。选项内部后续节点仍完整检查，不能通过入口过滤绕过错误依赖。
- 回放显示 Graph、Subgraph、Node、Edge 的对应关系。图示是解释架构的图，不是替模型生成的机器人计划。
