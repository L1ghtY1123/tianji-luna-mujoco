# 当前任务范围与可靠性修正

当前目标是先可靠完成有限任务：同一臂覆盖物体起点和固定放置区域，运行中不换臂；CAD 目录和放置配置固定。任意物体、任意放置姿态、换臂协作不属于本轮验收范围。

## 抓姿坐标

GraspGen 使用 Robotiq 2F-140。服务已将模型 base_frame 沿模型 +Z 195 mm 转到接触 TCP；Luna 只接受带该模型、坐标系和偏移声明的结果。Luna 将接触 TCP 对齐实际 `gripper_front_A/B`：A 为左臂，绕局部 Z 转 180°；B 为右臂，不附加旋转。实际前端 TCP 在各自 `TCP_Link_L/R` 的局部 +Z 185 mm 处。规划器直接使用指端 frame，不能再次把 195 mm 或 185 mm 加到目标上。

未知物体额外伸入量固定为 0，删除 `grasp_insertion_m` 设置及 UI 项，加载旧保存配置时丢弃该项。CAD 离线抓姿保留已有深度配置，默认 0。候选归档记录模型 TCP、实际 TCP 及转换矩阵；真实夹爪宽度、接触垫、非接触部件、环境和自碰撞检查保持有效。坐标转换不表示两个夹爪几何相同。

真实末端 +Z 只允许世界 +X 前方到 -Z 下方的连续扇区，左右偏离 XZ 平面默认不超过 30°，配置上限 45°。上下反向、朝机器人后方及过大横向姿态被排除。执行臂当前姿态用于选择平行夹爪的半转等价姿态；随后进行 IK、路径检查及实际规划端点 FK 朝向复核。

初次完整仿真还暴露了单物体编排歧义：scope=count 却绑定固定 ID 会缺少运行时选择节点。TaskSpec schema、编排说明和固定子图接口已共同明确：指定实例用 ids；从集合选 N 件才用 count，count=1 也必须显式 select_target 并绑定 $selected。校验器继续拒绝不一致图，不自动修补或增加 Responses 调用。

另一例暴露了 schema 说明错误：原说明声称 end 总需要显式出边，模型因此给终止节点生成自环。已修正为 failure/unknown end 无出边，success end 仅允许可选 unknown 回执失败边，并同步编排说明；不改变原有拓扑校验规则。

## 实现与证据边界

`PhysicalMemoryWriter` 接收物理记录、当前观测和回执，通过数据库事务提交后返回新的时间记忆；提交失败不替换已有内存。控制器负责图、任务账本和服务组合，空间记忆负责碰撞发布与失效，原始观测及测量缓存仍属于执行层。这是局部解耦，`PolicyController/RobotOperations/Runner` 的继承关系仍存在。

编排失败记忆的版本覆盖当前应用源代码、模型输入构造、固定子图、技能合同和说明、算法来源声明、机器人配置及冻结的运行参数。只有版本一致的失败进入当前编排；每类读取最近 128 个请求，按错误和不同前提保留示例。版本清单单独入库，旧记录不删除，不把历史规划成功或失败当作当前可行性证明。

每个永久 ID 的较早身份参考最多 3 次采集，选择最近参考、不同相机参考和最早确认参考；只取同一 world_key 的已确认记录，保留采集 ID、时间和请求来源。完整历史继续留在数据库。Decisions 关联统一使用带轮廓的 RGB 和包含目标标注的日期参考，不在档案阶段堆叠独立掩码图。每次请求记录输入合同版本与实现哈希。CURRENT 和 SAME_CAPTURE 图均校验采集绑定，历史图必须有采集和代次。

## 关联与推定的边界

初始描述和历史身份共享主体分配流程。各主体先独立提出当前掩码，尚不登记；跨相机关联后，如果多个主体竞争同一物体，用包含竞争描述、原选择和日期参考的一道 Decisions 题裁决归属。败选主体最多在剩余掩码中重选一次；明确归属的掩码在重选时排除。unknown 或再次冲突终止本次关联，事务不提交身份。没有暴露为冲突的共同误认仍可能发生，本轮不能证明完全纠正了误选。

抓后身份仍属于连续执行推定。程序验证目标、执行臂、运行、代次、观测、场景、动作版本和 Lift 完成时间，并要求抓前身份参考有同代次 Decisions 来源。复用抓前采集、错臂、旧运行或缺失来源均不能建立 attachment。它仍无法单凭执行连续性排除“意外夹到附近相似物体”的所有情况。

放置直接确认与推测确认均保留原始模型结果。推测交付要求此前持有同一目标、完整释放链、指定区域内实际释放和当前明确空爪；可见外掉反证为 failure，证据不足为 unknown。释放绑定哈希及抓取身份必须一致，错误目标、臂、运行和场景的回执不能支持推测成功。推测成功不产生物体当前实测位姿。

具体恢复耗尽或未覆盖异常进入已有固定 `terminal_failure_return` 子图，从实际关节尝试回观测位姿并停止，最终仍是原任务失败。无法证明回位安全时停止并报告 blocked；用户取消立即停止。收尾不继续原任务，也不放宽碰撞检查。
