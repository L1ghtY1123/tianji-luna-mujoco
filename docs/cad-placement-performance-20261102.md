## CAD 绑定与校验

SAM3 提供二维实例掩码；Decisions 根据当前永久 ID 主体、实际查询词及备用词、资产参考选择模型。名称只是检索线索，不要求 SAM3 的提示词字面等于 CAD 名称。项目规范名为 `blue_box`（蓝色盒子）和 `black_workpiece`（黑色工件）；外部 CAD 和离线抓姿库通过 `source_asset_id` 保持原索引、哈希和坐标系。左右盒子共享模型，但永久 ID、观测和世界位姿各自独立。

FoundationPose 将已选模型配准到当前 RGBD；相机外参把结果转换到世界坐标。三相机候选使用同一永久 ID，按有效观测尝试，候选须与关联相机当前深度和轮廓相符。掩码本身不能确定模型的三维平移和旋转。官方示例同样先加载 mesh，再以 RGB、depth、K、mask 调用 register：[FoundationPose run_demo.py](https://github.com/NVlabs/FoundationPose/blob/main/run_demo.py)。

数值校验检查 CAD 位姿与当前全部实测点、可见深度和轮廓的吻合程度，不重复判断自然语言。错误的位姿会把盒底/盒壁放入错误的碰撞位置，故保留校验。P14 的右盒实际出现过错误倾斜候选，被原门槛拒绝。

当前相机的 FoundationPose 候选均被拒绝后，允许以上次同代次、同 ID、同模型的已验证位姿为起点，对当前 RGBD 做一次有界 rigid ICP 更新；仍需通过全部原始当前数据的校验。不能直接发布历史位姿。某个 CAD 失败只记录该实例 geometry_rejected，不再丢弃同时有效的其他测量；建图仍拒绝该失败实例。
