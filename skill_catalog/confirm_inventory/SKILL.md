# confirm_inventory

`source_ref` means the original supporting surface, containing receptacle or source region of the selected input objects. It does not mean the input material itself; an object cannot be its own source. Source identity/origin, target membership, final destination and configured-region support visibility are independent questions.

Confirm the initial task membership and source/destination/work-area bindings against the original instruction and the observed permanent instances. Initial Responses inventory is a proposal. For processing tasks, select current input objects; future products need not exist yet. An operator-configured region is an external setting, not a visible marker. Confirm the requested region binding, not its imaginary painted boundary. For all/count tasks, independently check visible source completeness; do not infer hidden contents from a candidate count. Return confirmed bindings and ledger evidence, or unknown with the specific unmet question. No motion or capture is inserted.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses selects the initial graph; Decisions selects runtime recovery. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.
