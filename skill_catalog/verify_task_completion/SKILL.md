# verify_task_completion

Verify selected input lineages, delivery/processing receipts, requested count/order and actual final joint posture programmatically. Do not re-ask standard milestones globally and per object. For all scope, require current source absence and reuse the same capture/action-bound source answer when available. Only TaskSpec visual_completion_conditions add genuinely extra current visual questions using original frames. Missing receipts or unfinished input cannot pass; runtime does not reinterpret task language.

The executable parameter schema, facts, result bindings and outcomes come from the registered contract. See [current visual decision policy](../../docs/raw-decisions-20261111.md).
