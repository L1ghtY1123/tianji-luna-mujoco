# resolve_placement

Resolve a held-object pose within the established placement zone. Configured XY is fixed. Otherwise propose centers of 4, then 8, then 16 subdivisions as needed: Decisions chooses an XY candidate ID before numerical Z search. Stop at the first feasible candidate. Keep the grasp orientation unless the task explicitly requires another supported orientation. Start Z at the hard clearance plus the recorded tracking reserve and raise only if necessary. Check held-object/gripper geometry, current collision world, offline workspace and fixed-orientation IK. Decisions chooses semantics and candidate IDs; it does not certify numerical safety. Whole-region choices are operation proposals, not high-confidence physical facts. Extra spatial clauses use current annotated candidate footprints. plan_place separately checks the three-phase trajectory. Unknown never silently selects an alternate configured XY.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses selects the initial graph; Decisions selects runtime recovery. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.

The bound region and collision geometry must already be valid before grasping. While holding, an explicit `capture_mode=fresh` can acquire candidate images for a spatial-language judgment; it does not run SAM3/FoundationPose/OBB, rebuild the map or establish `observed=true`. Missing geometry cannot be repaired by these images. `observe_scene` and `perceive_placement_zone` are not held-object recovery operations.
