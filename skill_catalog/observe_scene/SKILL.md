# observe_scene

Associate current SAM3 subjects across three calibrated RGBD views with permanent inventory IDs. Update unknown objects as OBBs, known objects as FoundationPose CAD poses, and tables as measured cuboids. An explicit unknown_obb object skips CAD retrieval. Confirmed CAD model bindings persist; new poses use the best valid-depth camera, or instance-seeded tracking when its motion context is unchanged. Accept source-bound FoundationPose poses directly, without point/depth fit validation or ICP. The CAD/OBB path does not run the CPU robot-mesh ray filter. Both capture modes reuse unchanged sensor evidence; elapsed time or an unknown answer alone does not cause a new acquisition. Identical successful analysis is reusable; identical failed analysis is not repeated. Keep unobserved inventory records as dated history. This skill neither moves the robot nor publishes a collision map. Use a legal changed viewpoint when evidence is insufficient.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses selects the initial graph; Decisions selects runtime recovery. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.

Use this capability when current instance masks and geometric poses are needed. It is not a prerequisite for every Decisions request: release verification, visual task completion and visibility diagnostics can consume the current three-camera RGB directly. A confidence failure alone does not establish occlusion or authorize movement; diagnose not-visible, cropped and occluded evidence separately.
