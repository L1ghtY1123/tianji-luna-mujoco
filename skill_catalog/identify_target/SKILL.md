# identify_target

Bind an existing permanent instance ID as the current target, including a verified transformation product. Require current associated geometry. Reuse its confirmed creation/support/transfer evidence; only request a current support judgment if no usable support binding exists. This does not select a CAD asset, perform FoundationPose or generate grasps. Source support and intended destination are different relations. Unknown identity/support is reported for the graph to handle.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses selects the initial graph; Decisions selects runtime recovery. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.
