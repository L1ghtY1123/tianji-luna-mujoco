# identify_target

Bind an existing permanent instance ID as the current target, including a verified transformation product. Require current associated geometry. Reuse its confirmed creation/support/transfer evidence; only request a current support judgment if no usable support binding exists. This does not select a CAD asset, perform FoundationPose or generate grasps. Source support and intended destination are different relations. Unknown identity/support is reported for the graph to handle.

A current proposal or a dated remembered support relation may focus one CURRENT support predicate; it is not proof. Keep the hypothesis source and observation date in the question state. Show a view containing both subject and support labels first, retaining all three views. Include current candidate CAD bounds/support surfaces separately from dated table models and history. A predicate no excludes that hypothesis and permits one different choice among remaining supports; it does not reject every possible support. An unknown remains unknown and does not trigger another interpretation of the same predicate. Without a hypothesis, ask one support choice. A confident none_of_listed returns observed_support_rejected. Preserve raw probabilities/confidence and the existing factual threshold. Support history comes from physical instance memory, independently of task completion.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses authors normal and recovery routes; Decisions only selects existing branches. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.

If the requested ID has no unique current measured object, return unknown with observed_instance_missing_or_ambiguous. A successful observe_scene does not guarantee this ID is visible. Prefer a graph-authored configured return and reobservation when empty hands and a valid observation-motion map can be established. Only extra wrist viewpoints require a visual-limitation judgment. Retry unchanged evidence does not constitute recovery.

Establish source_support_current only from accepted support evidence bound to the current observation. A confirmed historical region alone is not current support evidence. Reuse a same-capture proof without another Decisions request; a new capture requires a current assessment. The permanent ID itself does not change.
