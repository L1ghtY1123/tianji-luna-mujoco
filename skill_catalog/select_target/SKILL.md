# select_target

Select an observed, registered, unfinished task input. Retain explicit role IDs and the user's explicit sequence. Decisions chooses spatial order from current labelled images and base coordinates, or compares accessibility when order is free. Missing comparison evidence yields unknown. Track verified completions for all, count and individual tasks.

参数、前提、效果、绑定和结果以同目录 contract.json 为准。所有跨技能恢复显式出现在 graph 中。
