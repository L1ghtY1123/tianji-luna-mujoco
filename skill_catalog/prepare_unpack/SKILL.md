# prepare_unpack

The verified release must belong to the current input and configured VLA work area. This skill consumes that existing receipt; it cannot recreate a receipt cleared by identify_target or identify_destination. Bind the intended work area before its transfer. Geometry refresh alone does not require rebinding an unchanged target.


Plan and execute both arms to the configured vla_unpack starting joints using the current measured collision scene. Both arm goals belong to that capability configuration. This does not process the object, verify a product, choose an arm for other transfers or force an observation return afterward.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses authors normal and recovery routes; Decisions only selects existing branches. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.
