# vla_unpack

When the user requires return and inventory observation after every delivery, the input's matching post-delivery observation receipt is required before processing. The graph must arrange it; this skill does not return or observe implicitly.

Invoke the configured processing capability for its bound input at the workbench input region and required starting posture. Its MuJoCo implementation replaces the package with a separate product; simulator truth stays inside the effect implementation. The action receipt does not prove the product exists visually. verify_unpack separately confirms the effect and creates the product ID. Preserve partial effects; do not blindly repeat processing.

Inputs, typed arguments, prerequisites, effects and recoverable results are defined in `contract.json` and the registered parameter schema. Responses selects the initial graph; Decisions selects runtime recovery. This skill executes only its selected operation. Current policy: `docs/cad-runtime-policy-20261102.md`.
