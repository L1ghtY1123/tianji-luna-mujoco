# choose_arm

**目的与调用时机：**校验并固定当前搬运阶段执行臂。

**输入与前提：**已有中心查表证据、尚未选臂/抓取且无恢复；输入 arm 和 evaluations。用户已指定或阶段已有绑定时直接遵守该约束，通常无需再次调用。

外层 JEV 的自动选臂依据当前阶段的实测起终点（显式 x/y/z），保留两臂完整离线查表证据；不混入上一段的几何。两臂均可达时，一端中央、另一端明显偏侧则优先偏侧端同侧臂；中央按查表 resolution_m 判断。侧向条件相当再比较当前距离。此偏好不构成姿态/路径可行保证。

**固定算法：**验证所选 A/B 的源/目的中心均可达，拒绝已尝试或违反绑定的选择，并在任务阶段记录 bound_arm。

**输出与状态：**arm_selected、arm、stage_index；不移动、不在线计算 IK。

**失败含义与边界：**none/不可达或与阶段绑定冲突时拒绝；规划失败不能在同一阶段自动换臂。中转进入新阶段可重新确定执行臂。

本技能内部不请求 JEV 决定子步骤或恢复。外层 JEV 选择已注册 skill 及必要参数，程序校验契约并执行固定算法。generation、反馈/观测 ID、scene token 与参数版本分别校验；Reset 后迟到结果不得应用。

当前注册目录共 16 项；完整流程、共享数值和验证边界见 [JEV skill 使用与实现手册](../../docs/jev-skills-guide.md)。文档同步不构成本轮部署、GPU 性能或物理成功验收。
