# plan_grasp

IK及抓取规划请求必须包含A/B夹爪实测开度；执行臂按全开规划，对侧保留实测值。SDK原始路径不再额外整段复查；最终插值命令仍验证10mm净距。闭爪后的模型变化由execute_grasp在lift前检查，不能把开爪规划结果当作闭爪几何的证明。

双臂必须在观测位姿，候选、地图、capture和执行臂版本一致。按官方公开接口先batched IK，再plan_grasp_batch生成approach/grasp/lift三段轨迹；项目封装仅完成位姿转换、碰撞配置、候选筛选及结果验证，不修改SDK算法。Demo轨迹批大小4，按分数分批，首个可行批中选择关节运动较短者。首池耗尽才允许按256/512/1000三轮共用180秒预算继续采样，错误或未知不当不可达重试。全部候选结果与过滤证据归档。输出经10mm世界碰撞检查及高级时间设置处理的命令，必须execute_grasp才执行；未成功则停止。

详细几何、预算、公开API与验证规则见 [技能手册](../../docs/luna-skills-guide.md)。
