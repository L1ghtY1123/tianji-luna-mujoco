# generate_grasps

在双臂观测位姿及当前全局RGBD场景下，为选定目标和执行臂调用GraspGen。按执行臂标定转换完整位姿（Z同向、X/Y相反）；先剔除Z偏离向下45度以上或指向机器人者，再沿通过候选工具+Z深入1cm一次。所有原始返回先预筛选，筛后按分数限制IK数量（首轮最多256），保留全生成结果及预筛选证据；必要时plan_grasp按有界预算触发后续轮，不由本技能自行循环。不调用逐候选Decisions，不执行运动。产出候选及几何/版本绑定；无有效方向候选或服务错误停止。

详细几何、预算、公开API与验证规则见 [技能手册](../../docs/luna-skills-guide.md)。
