## 使用

Ubuntu执行 `./start.sh`，停止 `./stop.sh`，状态 `scripts/demo-service.sh status`。网页 http://192.168.3.4:8350 ，后端8351、cuRobo8352、SAM38362、GraspGen8363。API配置只读挂载，项目不保存密钥。

Compose将 `LUNA_DECISIONS_TIMEOUT_S` 显式传入视觉客户端，默认90秒，可在项目`.env`中设置为1–180秒；该网络等待预算不增加模型调用或自动重试。

指令：“对于左侧盒子中的所有粉色待拆包物体，逐个拿出放到桌面目标区域，用VLA拆包取出黑色物体，再把黑色物体放到右侧盒子里。一个物体完成后再处理下一个。”也可指定数量。左腕初始RGB行顺序只决定物体编号，canonical ID和初始编号全程固定。执行顺序由初次观测的三视角RGBD实测质心到机器人基座的水平距离决定，由近到远；指定数量时选择最近N件。距离相同时沿原编号顺序，颜色和形状不参与排序；执行次序与显示编号独立。后续一次 `associate_inventory` Decisions接收同次三张CURRENT原图、候选标签/细节；仍有粉件时在同一请求加入INITIAL三RGB/原编号标签。`identity_N`确认当前工件角色，`wrapped_identity_N`结合可见外观、注册相机/原当前框连续性和实际逐ID操作记录确认原粉件身份，角色predicate概率及原身份choice confidence分别须达到0.8；全部剩余粉件仍须有已接受的camera2候选，但判断融合三视图，不要求每相机各自通过。唯一剩余角色、数量或位置不能单独证明身份。黑件在拆包视觉确认后建立独立entity ID，工序记录关联输入/产物；不要求粉黑外观同一性。右盒随机投放后的当前占据按集合表示，不逐成员重认ID。完整问题及unknown边界见[Decisions问题清单](docs/decisions-questions.md)。

## 执行与证据

一次gpt-6-luna Responses读取三RGB，生成固定清单、每个物体两段执行臂及有界skill程序。原粉件与黑色产物使用独立entity ID，工序ID串起输入、拆包和投放；桌面放置只是中间阶段，右盒Decisions确认才完成。不使用隐藏固定程序替代模型输出。

所有用户指定目标均为夹爪前端位姿。合法持物、attachment、实际释放反馈和撤离完成后，在当前位置采新三RGB核验当前粉件。实际TCP反馈结合抓取时实测物体参考与attachment几何，数值校验夹爪前端释放XY在固定共享区；release_position_check明确标注为开爪时刚体推导，不是释放后物体实测位姿，也不证明视觉成功。单次Decisions发送初始全部实体、活动ID、工序/生命周期记录、当前实测夹爪角度及开闭限位、INITIAL三RGB/注释和CURRENT三RGB/区域图，同一请求用两个独立predicate：place_result判断主桌上可见独立粉件，workpiece_still_held判断粉件仍被手指夹持；前者概率≥0.8且后者≤0.2才通过，不要求从RGB看清底部物理接触；不再要求模型重算公制XY或把高起轮廓装进桌面投影。概率≥0.8确认、≤0.2否定、中间unknown；原始probability不叫choice confidence。源盒粉件、机器人部件不计。INITIAL是历史，先历史后当前，头部当前图最后，三视角融合；动作记录和仿真真值不能代替当前像素。成功只推进table_released，不完成工序；同帧头部SAM3/RGBD更新粉件局部障碍，背景地图复用。旧非拆包路径仍使用choice place_result及最后一次的demo_unlisted_pink，不能把旧choice响应塞给当前predicate请求。

mock VLA完成后在当前自然位姿采同次三RGBD，以一个Decisions请求融合三CURRENT RGB、已确认桌面释放的BEFORE三RGB及主桌辅助图。unpack_result仅判断任一当前视图能否确认主桌上有独立黑件；机器人部件、盒内黑件不计，概率≥0.8通过。若看不清或未确认，只执行一次用户指定的回观测位姿分支：保留原地图，移除当前拆包输入/产物碰撞层（含过时粉件），桌子、盒子、其他实体保留；回位采新三RGBD再做一次Decisions。仍未确认则unknown停止；服务错误不触发回位或重试。确认后创建独立黑件ID，并保存该次capture、generation、实际双臂关节和工序绑定作为grasp_view_ready。随后observe_scene直接分析这次capture，不再move_to_observe，不要求头部相机独自提供深度；build_scene建立当前三视角地图后才能抓取。无仿真真值替代视觉、无隐式VLA重做，最多两次结果判断及一次换视角运动。

合法持物、attachment运输、实际开爪后，一次Decisions接收CURRENT三RGB、BEFORE三RGB及同盒辅助区域图。predicate current_item_added检查指定机器人右盒中当前可辨至少N+1个黑件，N仅为此前确认完成数，初始0来自用户场景先验。概率≥0.8确认、≤0.2否定、中间unknown；不另问in_right_bin、手指分离或旧黑件身份。多视图同件计一次，允许接触但须可分辨，机器人/桌面/盒外工件不计。动作历史和历史数量不证明当前数量。BEFORE仅为历史对照，不要求证明遮挡后曾为空。看不清或遮挡无法区分数量时不推进。成功完成独立产物及process，保留原始回答、计数、反馈链，不SAM、不建图。辅助盒区来自最新已发布占据与CAD壳边界，并按各帧标定投影，不取仿真真值。

对已选实体和执行臂建立唯一最新2cm TSDF/ESDF，仅清单实体入图，桌子复用首次RANSAC cuboid。粉件须双臂观测位姿；黑件可使用verify_unpack确认的当前抓取视图。校验实时关节与该capture一致，地图/清单/GraspGen必须同capture和generation。建立新图替换旧图及已消失粉件层，不将结果图片或仿真真值直接当深度；视图几何不足、版本或位姿改变时停止。 首次在双臂观测位姿，用三RGBD、一次Responses生成固定实体清单、两段臂和有界程序；SAM3多描述后一次Decisions关联候选。后续粉件抓取仍在观测位姿。拆包黑件允许verify_unpack已经确认的当前位置capture：不重新采图、不移动，校验工序ID、capture/generation和双臂关节未变后分析同次三RGBD。Decisions仍是三视图一起判断，至少一个视图的可信目标几何即可；黑件阶段其余粉件也可由任意相机提供，但不能丢失清单实体或不明深度。C编号仅为临时候选；确认身份后同一永久ID/相机合并掩码，不按描述新建ID。初始粉件ID保持，黑件用独立产物ID，完成件按右盒集合几何处理；原始/当前证据及未知候选归档。未知身份、缺几何、版本过期均停止，不把看不到的区域当作空闲。

SAM3用多种颜色、形状和位置描述。GraspGen固定三轮预算256→512→1000，最多1768个预算候选、3+6+10=19次服务调用；每次官方推理num_grasps=200、topk_num_grasps=100不变，各轮合并评分排序后截到本轮预算，实际返回不足时如实记录。只有当前池IK或规划确定性耗尽才进入下一轮，固定输入与共享规划deadline，错误/unknown不重试。左右工具坐标转换后，先剔除偏离向下竖直45°以上或指向机器人的候选；仅对通过者沿实际工具+Z前移1cm一次，再batched IK和plan_grasp_batch。算法输入、原始及筛选候选均保存回放。unknown、无解、无效输入和碰撞检查失败保留原因停止。
